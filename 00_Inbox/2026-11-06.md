# AI / Agent 战略雷达 · 2026-11-06

OpenAI 的隐私安全审查增加了客户可控存储方案，但“零保留”不等于不落盘；客户项目接入前要核对留存责任和项目隔离。

## 1. OpenAI PSP：零保留不等于没有日志，客户侧须承担留存

【事实】已核验 OpenAI Developers 公告及官方接入文档：ZDR with Private Safety Processing（PSP）支持离线自动安全审查，OpenAI 不保留客户提示词和回答副本；被安全分类器或批准的抽样策略选中的交互会加密写入客户控制的云存储。文档要求客户至少保留加密记录 30 天，并维护存储、权限及密钥授权。官方称内容在禁止人工访问的受保护运行环境内解密审查，只有限定的安全信号和运行元数据可以明文输出。这不是“完全没有记录”，也不是“没有安全审查”。PSP 按项目启用，启用后覆盖该项目全部 API 流量；需要对符合条件的模型使用不带 PSP 的 ZDR，应使用另一个对应配置的项目。

【影响】对昱桥的客户定制 Agent、以及未来可能接入云模型的器械识别项目，这是一种可评估的数据治理选项，不是可以直接向甲方承诺“不存数据”的依据。客户控制存储仍有运维和留存义务，也不代表推理在本地完成。此政策不能外推为当前 Hermes、Codex 订阅或 Claude Code 自动具备同样保护；更不能据此认定医疗数据上传已获合规许可。

【动作】建议将其加入下一次客户方案的数据边界核对项，而非立即迁移：明确哪些数据允许出域、哪些记录落盘、谁管理密钥及删除周期；核对项目实际保留策略和存储验证状态；不同留存要求的工作流使用独立项目。没有合同与账号配置证据前，不向客户承诺零落盘。本次已核验原帖与官方文档、完成近期日报去重；未上传客户数据、未改账号策略、未开通云存储或产生采购。

【证据】[OpenAI Developers 官方公告](https://x.com/OpenAIDevs/status/2118386439675420743)；[官方接入与客户责任文档](https://developers.openai.com/api/docs/guides/private-safety-processing)，重点参阅 How ZDR with PSP Works、项目级启用说明、Ongoing Customer Responsibilities。

【可信度/待核验点】上述机制与留存要求已由官方文档确认，安全保证属于厂商声明，未经本次独立审计。昱桥账号资格、具体端点适用性、地区限制、实际费用与合同条件尚未核验；本次不作启用或迁移建议。
