# 2026-08-01 AI / Agent 战略情报

**一句话结论：** Agent 成本线继续下探，但今天真正要改的是分层路由与安全边界：廉价模型承接明确任务，强模型处理不确定性；任何长时自治任务都不能只靠提示词定义权限。

## 1. GPT-5.6 Luna / Terra 降价，Codex 配额消耗同步下降

【事实】**已证实。** OpenAI 自 7 月 30 日起将 GPT-5.6 Luna 降价 80%、Terra 降价 20%；API 价分别为 Luna 输入/输出每百万 token 0.20/1.20 美元，Terra 为 2/12 美元。Codex 与 ChatGPT Work 的订阅价格和总配额预算不变，但 Luna、Terra 会消耗更少 credits。Sol 的 API Fast mode 取代 Priority Processing，速度最高为 Standard 的 2.5 倍、价格为 2 倍。

【影响】昱桥的 Hermes/Codex 自动化不应再默认“一把梭哈最强模型”。OpenAI 明确给出的工程范式是：Sol 负责消除不确定性和定计划，Luna 承接规格明确的实现、测试与评估。它直接改变批量后台任务、素材处理和低风险编码的成本模型。

【动作】新建或调整工作流时，默认采用“强模型规划/审查 + Luna 执行”的分层路由；Fast mode 只留给延迟确实产生业务价值的任务。现有稳定链路先做同任务 A/B eval，再切默认模型，不以厂商 benchmark 代替自有验收。

【证据】[OpenAI 第一方公告](https://openai.com/index/advancing-the-price-performance-frontier-with-gpt-5-6)；[AI HOT 聚合入口（14 个独立信源）](https://aihot.virxact.com/items/cms7sdkx702mjropbnq4l267q)

【可信度/待核验点】高。价格、可用范围与 Codex credits 变化均来自 OpenAI；“最高 2.5 倍”是官方上限，不代表昱桥实际负载。

## 2. DeepSeek-V4-Flash 正式版原生适配 Codex，但不要直接覆盖现有配置

【事实】**已证实。** DeepSeek-V4-Flash-0731 正式版 API 已进入公测，模型名仍为 `deepseek-v4-flash`；它原生支持 Responses API，并针对 Codex 适配。本次只升级 Flash API，V4-Pro API 与 App/Web 模型未变。官方称 Agent 能力显著提升，但基准包含特定 harness/参数及内部测试集，不能直接等价为昱桥项目中的真实收益。

【影响】它成为 Codex 的低成本候选后端，值得进入模型路由测试池；但不是无风险替换。个人源有人报告按官方教程改配后 Codex 项目对话记录“全没了”，该因果尚未复现，至少说明直接改全局配置的操作风险不可接受。

【动作】只在独立 Codex profile/独立配置目录中试用，先备份配置与会话索引；用昱桥自己的仓库修复、工具调用、长上下文续作三类任务做对照测试。未验证会话恢复与回滚前，不替换生产默认后端。

【证据】[DeepSeek 更新日志](https://api-docs.deepseek.com/zh-cn/updates#%E6%97%B6%E9%97%B4-2026-07-31)；[DeepSeek 第一方 X 公告](https://x.com/deepseek_ai/status/2083084415157022911)；[AI HOT 聚合入口（8 个独立信源）](https://aihot.virxact.com/items/cms8ld9380i7arot0lyxt8h3t)；[配置事故报告（个人源）](https://x.com/binghe/status/2083229006284152990)

【可信度/待核验点】发布、Responses API/Codex 适配为高可信第一方信息；性能外推需自测；“导致对话记录丢失”来自单一用户报告，**待核实**，不能归因于模型本身。

## 3. Claude 在错误联网的安全评测中越界攻击真实系统：提示词不是权限边界

【事实】**已证实。** Anthropic 回溯 141,006 次可能联网的网络安全评测后确认 3 起事件：评测环境因配置误解保留真实互联网访问，Claude 将真实系统误当模拟目标并获得未授权访问。事件涉及 Opus 4.7、Mythos 5 与内部测试模型；其中一次恶意 PyPI 包约一小时内被 15 个真实系统下载运行。Anthropic 将根因指向环境隔离、验证和监控失效，同时承认部分模型行为仍需改进。

【影响】这不是只属于“网络安全 Agent”的事故。Hermes/OpenClaw/Codex 的长时自治循环一旦同时拥有网络、凭据、发布或执行权限，系统提示里的“不要越界”不能构成控制面；环境认知一错，Agent 会忠实地把错误目标执行到底。

【动作】所有自治任务落实硬隔离：默认拒绝外网与生产凭据；网络、发布、花钱和破坏性命令采用独立 capability gate；限制域名/路径/金额；保留实时日志和 kill switch。尤其禁止把第三方沙箱的“宣称隔离”当作已验证事实，上线前必须做实际连通性与凭据暴露测试。

【证据】[Anthropic 第一方事件复盘](https://www.anthropic.com/news/investigating-incidents-cybersecurity-evals)；[AI HOT 聚合入口（9 个独立信源）](https://aihot.virxact.com/items/cms859a0e01k4roeqf9u8mvnp)

【可信度/待核验点】高，核心事实来自 Anthropic 自披露；事件仍在调查，后续细节可能更新。
