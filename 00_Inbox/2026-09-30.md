# AI/Agent 战略雷达｜2026-09-30

一句话结论：Pro 的额度账要重算，Sol 6.1 值得进入降本对照测试；Dots 已落地，但不构成迁走 Hermes 的理由。

## 1. Pro $200 调整额度口径：别把模型降价当成 Astra 补偿

【事实】已核验 Codex 负责人 Tibo 原帖：Pro $200 重新开放新订阅时调整用量计算，按 API 美元价值折算为旧方案的一半；承诺不恢复五小时限额。原帖同时提到 Sol、Luna 降价，但这不能证明 Astra 工作量得到等额补偿。原帖使用“明天”，本报告不据此推定昱桥账户的具体生效时刻。

【影响】Hermes 默认 Astra，若执行消耗该订阅额度，原来的长任务预算可能不再成立。这是订阅可兑换价值变化，不等于所有模型的任务数都减半，也不等于 API 单价上涨。

【动作】建议下一次安排长任务前核对账户用量页与套餐通知；先收紧无验收标准的重复审查与并行任务，不因额度焦虑直接升级更贵套餐。已回原帖核验；未访问个人账单、未购买、未改模型路由。

【证据】[Tibo 第一方说明](https://x.com/thsottiaux/status/2104823812042940713)；[AI HOT 聚合入口](https://aihot.news/items/gs96clovs726l3b5nd80ofnva)。AI HOT 与个人 X 的相关转述合并为同一事件。

【可信度/待核验点】负责人政策说明已证实；老用户过渡安排、个人账户生效时间、实际可完成任务量待核验。

## 2. GPT-6.1 Sol 上线：新增降本候选，不直接替换默认模型

【事实】OpenAI 官方发布页确认 GPT-6.1 Sol 可通过 API 的 gpt-6.1-sol 使用，并向 Plus、Pro、Business、Enterprise、Edu 用户的 ChatGPT Work 与 Codex 提供；尚未进入 Chat。标准 API 每百万 token：输入 $2、缓存输入 $0.10、输出 $10。官方称其标准输入输出单价为 Astra 的五分之一，并宣称部分智能体任务能力接近 Astra；后者是厂商评测，不是我们的实测。

【影响】投资证据整理、代码修错及小说生产的重复上下文任务新增降本选择。但低单价不保证低合格交付成本，更不能直接套用为订阅额度倍率。这里是新发布的 6.1 Sol，不是此前停用的 5.6 Sol。

【动作】建议在下一次既定评测中，将其与现用 Astra 放进同一真实任务、同一验收条件对照，记录返工、耗时和总成本；事实核验、工具参数正确率与完成率达标后再考虑分流。保留 Hermes 当前默认 Astra。已核验定价与可用范围，未调用付费 API、未改配置、未声称本地验证成功。

【证据】[OpenAI 官方发布与定价](https://openai.com/index/introducing-gpt-6-1-sol/)；[AI HOT 聚合入口](https://aihot.news/items/ewa77zkka92qb5lqukt70bfu8)。

【可信度/待核验点】发布、官方定价和公布的产品范围已证实；个人账号入口、Hermes 当前接入方式兼容性及我们工作负载上的质量与成本待实测。性能接近不是独立验证结论。

## 3. Dots 开始推出：常驻助手产品化，权限与计费边界比演示更重要

【事实】OpenAI 9 月 29 日发布 Dots：由 Astra 驱动，具备独立云电脑；在符合条件的市场向 Pro、Business Premium 用户逐步开放，Enterprise 等需管理员开启测试。首个 Dot 包含在上述个人适用套餐中；与 Dot 对话不占 ChatGPT 用量，但它启动或管理 Codex、ChatGPT Work 任务仍按正常额度计入。官方明确：后台主动研究使用只读工具；可能影响账户或分享信息的动作经过自动审核，是否需要人工批准取决于规则与安全要求，并非每次都由人批准。

【影响】“常驻在线＋记忆＋跨应用执行”正在成为平台提供的基础能力。对 AI 商业化的推断是：单纯包装通用助手更难形成差异，垂直流程、领域证据和可验收交付更值得投入。对现有三工具栈，新增的是可观察的替代方案，而不是已经证明更好的迁移目的地。

【动作】建议保持 Hermes 为主控；若以后评估 Dots，只用脱敏、只读的小任务验证任务连续性、证据可追溯与额度消耗。交易权限、浏览器凭据和客户敏感资料不作为试用素材；公开发布、花钱和破坏性动作仍保留明确人工批准。已核验官方权限与计费说明，未开通、未连接应用、未迁移数据。

【证据】[OpenAI：Introducing dots](https://openai.com/index/introducing-dots/)；[AI HOT 聚合入口](https://aihot.news/items/r9nae38v4x5x29jrec46olsl4)。个人 X 的 Dots 介绍与此前“o”预告不另列事件。

【可信度/待核验点】官方发布、权限设计与计费规则已证实；账户及地区是否开放、实际可靠性和自动审核效果待实测。商业化影响属于分析判断，不是已发生的收入结论。
