# AI/Agent 战略雷达｜2026-09-29

一句话结论：Sonnet 5.5 值得试，但不能把低单价当低任务成本；无人值守执行要分别验收“真完成”和“真隔离”。

## 1. Sonnet 5.5 上线：别为省钱直接切到 max

【事实】已核验 Anthropic 官方发布帖：Sonnet 5.5 已发布，官方宣称相较 Sonnet 5 输出更快、多数工作成本更低。但 Artificial Analysis 自己的评测原帖给出相反的高力度成本信号：在其 Intelligence Index、max effort 配置下，每任务成本为 7.60 美元，较 Sonnet 5 约高 50%。这不是同一工作负载下的直接矛盾，说明任务与思考力度决定实际账单。AA 明确其评测使用预发布部署，存在影响结构化输出的缺陷，并称公开版已修复、相关评测将重跑。

【影响】对 Claude Code 日常修错、文档整理及小说生产候选模型，新增一个可测试选择；不能据榜单接近 Opus 就认定质量相同，更不能把 API 单价外推成订阅额度更耐用。当前默认模型和三工具栈不必因此更换。

【动作】建议下一次既定任务用同一验收样本比较 Sonnet 与现用模型，明确 effort，记录合格交付成本、耗时及返工；不要以 max 作为省钱默认。已核验官方发布及 AA 原始评测，未付费调用、未切换配置、未声称完成本地对照实验。

【证据】[Anthropic 官方发布](https://x.com/AnthropicAI/status/2104633259925630995)；[Artificial Analysis 原始评测及局限](https://x.com/ArtificialAnlys/status/2104640155843989864)；[AI HOT 聚合入口](https://aihot.news/items/nastdr2zteysm2n0dg58d6tb1)。线索来源含 AI HOT，关键事实已回原始来源核验。

【可信度/待核验点】发布已证实；成本数据是评测机构在指定配置下的报告，不是我们的实测。公开版复测、个人账户可用范围、小说质量与实际额度消耗仍待验证。

## 2. Opus 5.5 官方指南明确：end_turn 不等于任务完成

【事实】Anthropic 官方提示词指南明确：长任务中的进度更新可能以纯文本和 end_turn 结束，若调度器把它当任务完成，无人值守运行就会提前停止。官方建议用未完成清单或独立完成判定继续推进，并把同一任务的自动续跑限制在两三次；已启动的后台任务或子代理尚未返回时，不能算完成。指南还建议从显式 medium effort 起测，而不是原样继承旧模型的高力度设置。

【影响】这直接影响以后在 Hermes 或 Kanban profiles 中接入 Opus 5.5 的长任务验收：一份漂亮总结不是完成信号。是模型特定的集成风险，不代表当前 Hermes 默认 Astra 已出现该缺陷；也不是今日新发布模型的消息。

【动作】建议将“未完成清单为空、必需测试有真实结果、后台任务已结束或明确交接”设为完成门槛；卡住时有限续跑并报告阻塞，不无限重试。下次接入或升级 Opus 的验收应包含中途只汇报不执行的用例。已核验文档并记录建议，未修改调度器、提示词或任何 profile。

【证据】[Anthropic：Opus 5.5 提示词指南](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-opus-5-5)；[AI HOT 聚合入口](https://aihot.news/items/qljqxvzy0bb98x5hvfbksdg0m)。

【可信度/待核验点】官方行为说明与建议已核验；现有执行框架是否已覆盖、修改后是否有效，尚未本地审计或实测。本文不把文档收录时间当成发布时间。

## 3. NVIDIA 新安全平台：值得借鉴边界，不值得立即采购硬件

【事实】NVIDIA 9 月 28 日技术原文介绍 Open Agent Safety Platform：OpenShell 是采用内核级隔离的开源运行时，限制文件、网络、工具、进程和凭据访问；Sentry 把额外的独立监控与执行层放到 BlueField 硬件。新增的是分层安全平台及参考设计，不是 OpenShell 今天才首次出现。厂商强调约束应在 Agent 无法自行修改的独立层执行。

【影响】相较此前已报告的 OpenAI 停机缺口，今天新增了可考察的工程实现候选。对持有研究资料、登录凭据及潜在交易权限的自动化，重点是权限隔离与真实断路，不是再加一句安全提示词。该公告不能证明它可直接装入当前 Mac 环境，也不能证明我们的环境已经安全。

【动作】建议未来隔离方案先验收：普通研究任务拿不到交易密钥和浏览器登录凭据；网络只通向授权目标；停止条件触发后确实不能继续外部写入。OpenShell 仅列为候选，先查兼容性与维护成本，不更换框架、不购置 NVIDIA 硬件。本次已核验技术原文，未安装、未修改凭据或网络权限。

【证据】[NVIDIA 第一方技术文章](https://developer.nvidia.com/blog/nvidia-open-agent-safety-platform-a-reference-for-continuous-in-silicon-agent-monitoring/)；[AI HOT 聚合入口](https://aihot.news/items/s5on5dsnixevj7j9lfjemhz3o)。事实取自技术正文，不依赖页面顶部的 AI 摘要。

【可信度/待核验点】产品架构与厂商声明已核验；抗逃逸效果、Mac 兼容性及 Hermes/Codex/Claude Code 集成成本未实测，不宣称绝对安全。
