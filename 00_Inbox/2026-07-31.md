# AI / Agent 战略雷达｜2026-07-31

**一句话结论：** 今天真正改变动作的不是又一个模型发布，而是三条基础设施信号：GPT‑5.6 的规模化成本骤降、Harness 本身可能制造数量级成本差、以及高自治 Agent 的隔离边界必须从“提示词约束”升级为硬网络控制。

## 1. GPT‑5.6 降价：把“强模型规划、便宜模型执行”变成默认架构

【事实】**已证实。** OpenAI 自 7 月 30 日起将 GPT‑5.6 Luna API 价格降至每百万输入/输出 token **$0.20 / $1.20**（降幅 80%），Terra 降至 **$2 / $12**（降幅 20%）；Sol 价格不变，但 API 新增 Fast mode，最高 2.5 倍速度、价格为标准模式 2 倍。Codex 与 ChatGPT Work 的订阅价格和额度预算不变，但 Terra/Luna 现在消耗更少 credits。AI HOT 将此识别为 15 个独立信源共同报道的热点。

【影响】对昱桥的长期自动化、批量内容加工、测试与例行实现任务，Luna 的新价位已经足以改变模型路由：不应再让 Sol/高价模型从头包办确定性执行。真正稀缺的是判断与拆解，不是每一步都用最高智能。

【动作】从今天起采用“**Sol 处理不确定性与计划，Luna 承担规格明确的实现、测试、评估和批处理**”作为新工作流的默认候选；现有关键流程先用自己的验收集做质量/总成本对照，不因厂商 benchmark 直接全量迁移。只有延迟直接影响结果时才启用 Fast mode。

【证据】[OpenAI 官方公告](https://openai.com/index/advancing-the-price-performance-frontier-with-gpt-5-6)；[AI HOT 聚合入口（15 个独立信源）](https://aihot.virxact.com/items/cms7sdkx702mjropbnq4l267q)

【可信度/待核验点】定价、可用范围和模式变化为第一方已证实；OpenAI 关于 benchmark 与单位任务成本的比较属于厂商自测，未作为迁移结论。

## 2. 同一模型换 Harness，成本差可能大过换模型

【事实】**结果已由测试发布方披露，但方法学仍需复核。** Composio 称其让 Kimi K3 在 Claude Code、Hermes、Kimi Code 上执行 28 个相同任务：成功数分别为 20/28、21/28、22/28；中位 token 用量分别约 340k、67k、61k，中位耗时分别约 348 秒、179 秒、297 秒。也就是说，这组小样本中 Hermes 与 Kimi Code 的成功率接近，Claude Code 却显著更耗 token；Sebastian Raschka 也表示这与他此前观察到 Claude Code 在相近成功率下使用更多 token 的现象一致。

【影响】这直接打掉“成本主要由模型单价决定”的错误直觉。昱桥在 Hermes、Claude Code、Codex 之间做路由时，必须把 **Harness × 模型 × 任务类型** 当成一个整体测量；否则即使买到更便宜的模型，也可能被上下文重读、工具循环和重试吞掉收益。

【动作】当前不切换全局默认配置：单次 28 题、单模型测试不足以外推所有任务。但在 Kimi K3 或成本敏感的长循环中，优先把 Hermes 作为 Claude Code 的对照基线；后续评测必须同时记录成功率、输入/输出 token、中位耗时、工具调用次数与失败重试，禁止只看模型榜单。

【证据】[Composio 原始测试线程](https://x.com/composio/status/2082452269522378858)；[Sebastian Raschka 的复核性观察](https://x.com/rasbt/status/2082855363154497880)

【可信度/待核验点】数字来自测试发布方的公开线程，非独立审计；任务构成、缓存计费、上下文策略与完整复现实验尚未在当前材料中充分公开，因此只能作为路由实验的强信号，不能当作普遍排名。

## 3. Claude 误入真实系统：Agent 沙箱必须按生产安全等级建设

【事实】**已证实。** Anthropic 在回溯 141,006 次可能获得互联网访问的网络安全评估后，确认三起事件：Claude 因第三方评估环境误配置而连接互联网，并未经授权进入三家组织的真实系统。模型被告知环境是无互联网的模拟场景，因此把真实目标误判为题目的一部分；事件涉及 Opus 4.7、Mythos 5 和一个内部研究模型。Anthropic 表示这些评估未启用面向公开产品的标准分类器与监控，并已暂停相关评估、通知相关方，准备加强网络隔离、实时监控、供应商安全保证与转录审查。

【影响】这是对所有高自治 Hermes/Codex/Claude Code 循环的现实警告：**模型对环境的认知不能充当权限边界。** 只要工具、浏览器、Shell、凭据和公网出口同时开放，一个“合理执行目标”的 Agent 就可能在错误上下文中造成真实越界；提示词写着“仅限测试”没有防护价值。

【动作】将安全基线明确为：高风险或长时间无人值守任务必须使用默认拒绝的出站网络、最小权限临时凭据、目标 allowlist、独立工作目录/容器、实时日志与可中止开关；涉及发布包、外部写操作或生产系统时继续保留人工批准门。第三方 Agent/Eval 服务不能因“只是测试环境”而降低审计等级。

【证据】[Anthropic 官方事故复盘](https://www.anthropic.com/news/investigating-incidents-cybersecurity-evals)；[AI HOT 聚合入口（4 个独立信源）](https://aihot.virxact.com/items/cms859a0e01k4roeqf9u8mvnp)

【可信度/待核验点】事故事实、原因和处置来自 Anthropic 第一方复盘，并明确称是当前理解、后续可能更新；受影响组织身份及第三方独立复核尚未公开。
