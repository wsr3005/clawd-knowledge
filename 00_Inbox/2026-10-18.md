# AI / Agent 战略雷达 · 2026-10-18

一句话结论：第三方密钥托管需要收紧；DeepSeek 新搜索接口值得进入数据源评测，但不急着换主模型。

## 1. OpenCode Console 披露安全事件：密钥托管不是无成本的便利

【事实】已核验 OpenCode 官方公告：发生安全事件，影响其 Console 用户中的 1.4%，范围是绑定外部服务商的一部分用户；官方称已邮件通知受影响者，并与 Anthropic、OpenAI、Google 协作处理。公告发布时事件仍在处理中。“蒸馏攻击”是官方描述，不代表已公开完整入侵机制。不能把 Console 事件泛化为所有本地 OpenCode 用户受影响。

【影响】昱桥主栈为 Hermes、Codex、Claude Code，现有证据不能证明我们的账户或密钥受影响。真正需要调整的是接入边界：为了免费模型或统一入口把生产密钥交给第三方，会扩大凭证暴露范围；这不是单纯的工具体验选择。

【动作】建议不向未经审查的第三方控制台新增生产密钥；如曾在 OpenCode Console 绑定外部服务商，核查官方通知及用量，确认暴露后到服务商撤销并更换对应密钥。后续集成采用用途隔离、最小权限与可用的预算限制。此次已核验官方公告，未读取秘密、撤销密钥或改动运行配置。

【证据】[OpenCode 官方公告](https://x.com/opencode/status/2111519637049319818)；聚合线索与署名：[AI HOT](https://aihot.news/items/niwlbjnktvqnoi9st6lakhlo2)。

【可信度/待核验点】事件及官方声明的影响范围已核验；昱桥是否使用过相关 Console、是否存在异常用量未核验。第三方转述的具体泄露方式及赔偿说法不作结论；“没收到邮件”是官方判断，不替代对已知绑定账户的核查。

## 2. DeepSeek 新版与独立搜索接口：优先评测检索，而非迁移主模型

【事实】已核验官方发布：DeepSeek-V4.1-Flash-1017 上线网站、App 与 API；更快、更短、基准更强属于厂商自报，未在我们的任务中复现。此次同时开放独立 Search / Fetch JSON 接口，官方文档列出 `/v1/tools/search` 与 `/v1/tools/fetch`，使用 DeepSeek API Key。两者各按每千次成功请求 0.75 美元计费；失败、空搜索结果、超时不计费。Search 支持站点、语言和日期过滤，Fetch 返回网页 Markdown。

【影响】对股票政策证据链与每日情报，新增的是可单独评估的检索和正文获取来源，不要求先迁移生成模型。中文原文命中率、发布时间准确性与可追溯性，比发布榜单更影响当前工作。文档中的摘要与权威分仍不能替代原文核验。

【动作】建议维持 Hermes＋Codex＋Claude Code 主栈，把该接口列入下次检索数据源评测：用已有政策原文问题比较命中、正文可取性、日期准确性及实际账单，再决定是否接入。此次已核验接口和计费文档，未调用付费 API、安装新框架或切换模型。暂不采纳二手“11 月 1 日起收费”的统一口径。

【证据】[DeepSeek 官方发布](https://x.com/deepseek_ai/status/2111375640717033777)；[Search / Fetch 官方文档与计费](https://api-docs.deepseek.com/guides/search)；聚合线索与署名：[AI HOT](https://aihot.news/items/w34qm27sedtziwxig5ub9wwhr)。

【可信度/待核验点】发布、接口与文档价格已核验；账户可用性、真实检索效果和总成本未实测。文档另称 Claude Code / Codex 特定内置搜索路径有上线后初期免请求费安排，具体起收日期另行公告，不等于独立 API 免费，也不能泛化到所有配置。中文更新日志本次提取未显示 1017 条目，因此版本上线采用官方 X 原帖佐证。
