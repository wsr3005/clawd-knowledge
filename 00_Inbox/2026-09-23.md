# AI/Agent 战略雷达｜2026-09-23

一句话结论：本轮值得调整的是任务分层与成本核算，不是追榜换主力；Hermes 保留 Astra，Opus 5.5 与 Sol/Luna 进入有验收门槛的候选池。

## 1. Opus 5.5：降价与可保留的额度重置已确认，接入还有兼容性门槛

【事实】已核验 Anthropic 发布原文：Opus 5.5 已发布，API 标识为 `claude-opus-5-5`；每百万输入/输出 token 为 4/20 美元，缓存读取为 0.20 美元。官方宣布提高 Pro、Max、Team 的五小时额度，并向订阅用户提供可自行选择使用时机的额度重置。官方称典型负载运行成本比 Opus 5 低 40%，这是厂商测试结论，不是我们的实测账单。官方同时说明：thinking 不能关闭；preserved thinking 约束适用于 2026-08-31 起创建的 API 账户；大多数网络安全任务会转交 Opus 4.8。

【影响】Claude Code 的工程与研究任务有新的成本候选；小说写作也值得纳入既有 profile+model 评测，但“沟通更自然”不能等同于中文小说质量提升或通过朱雀。自定义上下文编辑与安全审计任务不能假设无缝迁移；API 单价下降也不能直接当成订阅额度同比增加。

【动作】建议先查看账户内可用的额度重置，留到真正遇到额度瓶颈时使用；不采纳未经官方页面确认的具体到期日。以既有代码任务和小说实验稿做同条件对比，记录验收通过、返工、时间及实际用量，再决定是否切换。已完成官方价格、额度政策与兼容性警示核验；本次未改模型配置、未兑换重置、未发起付费测试。

【证据】[Anthropic 发布原文](https://www.anthropic.com/claude-opus-5-5)；[AI HOT 聚合入口](https://aihot.news/items/cmucwy58v0rskroedmv35n8ji)。候选线索来自 AI HOT、权威 X 与个人 X，按同一发布事件合并。

【可信度/待核验点】发布、标价与官方政策可信度高；个人账户实际额度、重置可用性、接入兼容性及本地任务效果待实测。性能和运行成本优势只归因于厂商报告，不作独立证实。

## 2. Sol/Luna 与 GPT-6 缓存更新：先降低批量处理成本，别动高风险判断层

【事实】已核验 OpenAI 原文：推出 GPT-6 Sol/Luna，每百万输入/输出 token 分别为 Sol 2/10 美元、Luna 0.10/0.50 美元。同期缓存公告明确：合格的共享前缀在 30 分钟窗口内复用可获得缓存优惠，缓存输入最高优惠 90%；提供命中率看板与失效诊断工具。官方建议保持工具定义、schema 和顺序稳定，通过 allowed_tools 限制可调用工具，而不是删除定义；也提供保留缓存的推理强度调整方式。

【影响】对瓶颈优势雷达，新闻初筛、实体抽取和格式整理有低价模型试验空间，但政策因果链、证据冲突与公司判决不能仅因便宜就降级。小说的素材整理可以与正文创作分层。长上下文 Agent 的费用不仅取决于模型，还取决于上下文与工具定义是否频繁变化。以上是工作流推断，不是已验证的节省结果。

【动作】默认继续用 Astra 承担 Hermes 主会话和关键判断；建议先把 Luna 纳入低风险批处理候选、Sol 纳入有测试约束的执行任务候选。比较时同时看漏报、错误、重试和实际任务成本。缓存优化先核查实际调用链、缓存用量字段和账单，再决定是否改接入；OpenAI API 公告不能直接证明当前 Codex OAuth 通道获得相同计费收益。已核验两份官方原文，未修改路由或执行付费调用。

【证据】[OpenAI 模型发布原文](https://openai.com/index/introducing-gpt-6-sol-and-luna)；[OpenAI 缓存更新原文](https://openai.com/index/better-prompt-caching-for-gpt-6)；[AI HOT 模型聚合](https://aihot.news/items/cmud1y2ku039iro5ysl7pq6d3)；[AI HOT 缓存聚合](https://aihot.news/items/cmud4mu5303n5roa915w7f1ja)。发布及配套缓存能力合并为一个成本决策事件。

【可信度/待核验点】标价和缓存机制已从第一方核验；不照搬“全部减半”口号，以具体价目为准。不将特定评测幻觉率外推到日常任务。当前账户可用性、Hermes 接入支持和端到端成本待核验。
