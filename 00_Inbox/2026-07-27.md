# AI / Agent 战略情报｜2026-07-27

**一句话结论：** Agent 工程正在从“堆规则”转向“轻上下文＋按需 Skills＋验证闭环”；同时，手机端执行层与音乐生成后的可编辑交付链都出现了值得小规模验证的新入口。

## 1. Claude Code 官方把新版模型的系统提示词削减逾 80%

【事实】Anthropic Claude Code 团队称，面向 Claude Opus 5、Fable 5 等新模型，删除了超过 80% 的系统提示词，编码评测没有可测损失。官方建议：让模型依据周边上下文判断；把验证、代码审查等拆成按需加载的 Skills；保持 `CLAUDE.md` 轻量，只记录项目特有陷阱；避免在系统提示词和工具描述中重复规则；以测试、代码、HTML mockup、rubric 等高保真引用替代冗长说明。Claude Code 还提供 `/doctor` 来帮助压缩 Skills 与 `CLAUDE.md`。

【影响】这直接挑战“规则越多越可靠”的 Agent 配置思路。对 Hermes、Codex、Claude Code 和 OpenClaw 的长期维护而言，重复或冲突规则会浪费上下文并增加决策摩擦；真正可靠的约束应尽量下沉到工具接口、权限边界和可执行验证，而不是继续扩写提示词。

【动作】下一轮上下文维护采用“删而不是加”：盘点重复规则与示例，把仅在特定任务需要的流程拆入 Skills，把不可妥协的结果要求固化为测试/验收脚本。Claude Code 项目先运行 `/doctor` 做基线诊断；不盲目照搬“删 80%”这一比例。

【证据】[Anthropic / Claude 官方博客](https://claude.com/blog/the-new-rules-of-context-engineering-for-claude-5-generation-models)；[作者 Thariq Shihipar 的原始发布](https://x.com/trq212/status/2080710971228918066)

【可信度/待核验点】高，第一方团队复盘。其“无可测损失”针对 Claude Code 自有编码评测与指定新模型，不能外推为所有模型、所有 Agent 都应机械删减同一比例。

## 2. Open Minis 全量开源：手机端出现可复用的 Agent 执行层

【事实】Open Minis 已公开 iOS 与 Android 代码，采用 GPLv3。官方仓库确认其提供设备内 Alpine Linux 沙箱、浏览器自动化、持久记忆、Skills、MCP 和系统能力接入；并声称 Claude、Codex、OpenClaw、Hermes Agent 的 `SKILL.md` 通常可直接复用。模型侧仍需连接 Claude、GPT、Gemini、OpenRouter 或兼容 API，因此“on-device”主要指执行环境、文件与设备工具，并不等于模型推理全部离线。iOS 受沙箱限制，不能像 Android 无障碍服务那样控制任意 App UI。

【影响】它不是 Hermes/OpenClaw 的替代品，而是潜在的移动执行端：可把已有 Skill 迁移到手机，接入日历、提醒、HealthKit/HomeKit、剪贴板或 Android 跨 App 自动化。最大价值是复用现有 Skills，而不是重建一套移动 Agent；最大风险是 API 数据外发、系统权限面扩大和 GPLv3 对二次分发的约束。

【动作】列入移动 Agent 小规模试验：先用非敏感的“剪贴板/网页 → 日历或提醒”流程验证 Skill 兼容性、稳定性和权限边界；在确认数据流、API 成本与许可证影响前，不接管高权限或商业分发工作流。

【证据】[OpenMinis 官方 GitHub 仓库](https://github.com/OpenMinis/OpenMinis)；[官方产品与能力说明](https://openminis.app)；[作者原始发布](https://x.com/wsvn53/status/2081035242715140377)

【可信度/待核验点】高（开源代码、许可证和文档可查）；“已服务数万用户”等采用方数据仅见作者自述，本条不据此作决策。

## 3. Suno 新增 MIDI 导出，生成音乐开始更像可继续生产的素材

【事实】Suno 官方宣布网页端与移动端新增一组能力，包括高级音轨分离、将 stems 导出为 MIDI、歌词协作与自动保存、截图生成歌曲，以及 CarPlay/Android Auto。官方帖未说明各功能的套餐门槛、地区范围、导出质量或商业使用条款。

【影响】其中真正改变商业化工作流的是 MIDI 导出：AI 生成结果不再只能作为成品音频，可进入 DAW 做编曲、换音色、修旋律和人工精修，适合短剧、视频、小说宣发配乐从“一次生成”升级为“AI 草稿 → 可编辑制作”。其余功能更多是便利性更新。

【动作】后续音乐项目优先测试“分轨/MIDI → DAW 精修”的交付链；在用于商业客户前，必须实测 MIDI 准确度，并核对当前订阅层级、版权与商用授权，不把官方功能清单误当作已确认的商用许可。

【证据】[Suno 官方原始发布](https://x.com/suno/status/2081443050312843765)；[AI HOT 聚合入口](https://aihot.virxact.com/items/cms24qise02adro9fp4xzdhyd)

【可信度/待核验点】功能发布本身为高可信第一方信息；套餐、地区、质量和商用权利均待实际账户与最新条款核验。
