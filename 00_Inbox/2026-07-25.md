# AI / Agent 战略雷达｜2026-07-25

**一句话结论：** 今天真正该改的不是再堆工具，而是调整模型与上下文底座：Opus 5 进入高难 Agent 候选，长提示词应转向按需加载，Codex 跨目录项目可直接消灭资料复制。

## 1. Claude Opus 5：高难 Agent 的性价比基线换代

【事实】Anthropic 已于 7 月 24 日发布 Claude Opus 5，API 价格为每百万输入 Token 5 美元、输出 Token 25 美元，与 Opus 4.8 相同；Claude Max 已将其设为默认模型，Claude Pro 将其列为最强模型。官方评测称其在 Frontier-Bench v0.1 上超过 Opus 4.8 两倍，并在 CursorBench 3.2 最高 effort 下接近 Fable 5 峰值、单任务成本约为后者一半。AI HOT 显示该事件有 19 个独立信源报道。

【影响】这改变 Claude Code 与复杂自动化的模型路由：原先需要在 Opus 成本和 Fable 能力之间取舍的高难调试、长链执行、PPT/研究型交付，现在有了更现实的中间档；但厂商评测不能替代昱桥自己的任务集。

【动作】将 Opus 5 纳入“高难、开放式、需要自检”的默认候选，不做全量盲切；先用真实的代码修复、跨工具自动化和长文/PPT任务，与当前主力模型做同题 A/B，按成功率、返工轮次和总成本决定路由。

【证据】[Anthropic 第一方发布](https://www.anthropic.com/news/claude-opus-5)；[AI HOT 聚合入口](https://aihot.virxact.com/items/cmrz7mrck00gprox8j0j9qfst)

【可信度/待核验点】发布、价格、可用范围及官方评测陈述均由第一方原文确认；性能数字属于 Anthropic/合作方评测，尚未用昱桥工作流独立复现。

## 2. Claude 5 上下文工程反转：删规则，做渐进披露

【事实】Anthropic 表示，面向 Opus 5、Fable 5 等模型，Claude Code 删除了超过 80% 的系统提示词，在其编码评测中没有可测损失。其新建议是：CLAUDE.md 只保留仓库定位和真正的坑；验证、评审等长流程拆成按需 Skill；减少重复、冲突规则；优先设计清晰工具接口而非堆调用示例，并提供 `/doctor` 辅助精简上下文。

【影响】这正面挑战“规则越全，Agent 越稳”的旧做法。Hermes、Claude Code、Skills 与项目级指令若持续膨胀，会浪费上下文并制造冲突；未来优势来自路由与按需装载，而不是巨型总提示词。

【动作】立即停止向全局提示词继续堆一般性规则；下一轮维护按“全局最小约束 → 项目 gotchas → 按需 Skill/参考文件”三层审计，并用 `/doctor` 检查 Claude Code 配置。安全、发布、花钱、不可逆操作等硬边界仍保留，不照搬“删 80%”。

【证据】[Claude 第一方上下文工程指南](https://claude.com/blog/the-new-rules-of-context-engineering-for-claude-5-generation-models)；[AI HOT 聚合入口](https://aihot.virxact.com/items/cmrz7ov4300lfrox82ri8kia1)

【可信度/待核验点】“超过 80%”及“无可测损失”为 Anthropic 自述；适用于 Claude 5 代模型，不能直接外推到 Hermes 当前模型或所有第三方 Agent。

## 3. Codex 支持单项目跨多个本地文件夹

【事实】OpenAI Developers 官方确认：一个 Codex 本地项目现在可加入多个相关文件夹，Codex 能跨目录读写代码、文档和参考资料，同时保留一个主文件夹作为 Git 根；Git 操作、Review、PR、AGENTS.md 与 Skill discovery 均由主文件夹负责。

【影响】这直接解决“知识库、代码仓、素材目录分散”时复制文件或把多个仓库硬塞进同一目录的问题，也更适合让 Codex在项目代码之外读取 clawd-knowledge、规范或素材；但主目录选错会导致 Git 与技能发现落在错误仓库。

【动作】后续跨仓任务优先建立多文件夹 Codex 项目，不再复制参考资料；把真正要提交代码的仓库设为主文件夹，其他目录只作为资料/协作范围，并在执行前明确哪些目录允许写入。

【证据】[OpenAI Developers 第一方公告](https://x.com/OpenAIDevs/status/2080390328880951299)

【可信度/待核验点】能力与主文件夹职责已由官方账号确认；具体客户端版本、灰度范围及跨目录权限提示未在该公告中展开，首次使用需以本机界面为准。
