# 2026-09-04 AI / Agent 战略情报

**一句话结论：** Agent 的主战场正从“更会回答”切到“更长时间地操作真实软件”；今天最值得做的不是追逐 AGI 口号，而是用自己的任务验收 Astra 与 Claude 的执行质量，同时收紧高权限自动化边界。

## 1. GPT-6 Astra：能力跃迁成立，但 99.9% 不是同条件裸模成绩

【事实】**已证实。** OpenAI 发布 GPT-6 Astra，定位于 computer use、浏览、软件工程和专业工作；未来数日向 ChatGPT Plus、Pro、Business、Enterprise、API 与 AWS 推送。API 标准价为每百万输入 token 10 美元、输出 token 50 美元，Fast 模式最高 2.5 倍速、价格为标准模式 2 倍。OpenAI 自报 OSWorld 2.0 为 72.6%，约 40 分钟/任务；GPT-5.6 Sol 为 65.7%，约 75 分钟/任务。ARC Prize 独立披露：统一 Standard harness 得分 62.7%，保留供应商 opaque reasoning state 并使用 compaction 的 Provider Adapter harness 才达到 99.9%。OpenAI 同时确认 Astra 是其首个达到 Preparedness Framework “Critical” 网络安全能力等级的模型。

【影响】这不是普通模型换代，而是对 Hermes/Codex 长任务、浏览器操作、PPT/网站/3D 等成品工作流的潜在重构；但宣传中的 99.9% 高度依赖上下文管理与 harness，不能直接外推为真实开放任务成功率。价格高于 Sol，是否划算必须看完整任务成本、返工率和人工接管次数，而不是 token 单价。

【动作】Astra 到账后，把它纳入而非直接替换现有主模型：选 5 类真实任务做 A/B——跨仓库修复、网页操作、PPT/HTML 成品、长时研究、定时自动化；记录一次通过率、墙钟时间、总成本、人工接管和越权/误操作。涉及账户、密钥、发布、付款和删除的 computer-use 任务继续强制人工确认；Critical 网络能力意味着不要给无隔离环境的广泛凭据。

【证据】[OpenAI 发布页](https://openai.com/index/gpt-6-astra) · [OpenAI 安全概览](https://openai.com/index/safety-overview-gpt-6-astra) · [ARC Prize 独立评测](https://arcprize.org/blog/astra) · [AI HOT 聚合入口](https://aihot.virxact.com/items/cmtm7yl5s01d6robnym0jg0b7)

【可信度/待核验点】发布、价格、开放范围与 Critical 定级为第一方信息；性能多数仍来自 OpenAI 自测。ARC Prize 明确提醒，62.7% 与 99.9% 对应不同 harness，且 ARC-AGI-3 是封闭、确定性环境，不等于 AGI 或现实世界鲁棒性。

## 2. Claude Code / Cowork 获得 macOS 后台电脑操作

【事实】**已证实。** Claude 官方宣布，Claude Code 与 Cowork 现在可在后台点击、输入并打开桌面应用；该能力处于 beta，面向 macOS 桌面端的 Pro 和 Max 计划，可在 Settings → General → Computer use 开启。

【影响】这直接补上 Claude Code 从终端/代码走向 GUI 应用的执行层，可用于把资料整理、浏览器后台操作、文档/PPT 流程与编码串成一条长链。对昱桥的价值不在“会点鼠标”，而是前台继续工作时让另一个执行面并行跑；代价是桌面权限和误操作半径显著扩大。

【动作】只用隔离、可回滚的小任务试跑：先从公开网页采集、测试账号录入、只读文件整理开始；禁止首轮接触主账号会话、密码管理器、支付、公开发布和不可逆删除。验收重点看后台运行时是否抢焦点、跨应用状态是否稳定，以及失败后能否恢复，而不是演示观感。

【证据】[Claude 官方公告](https://x.com/claudeai/status/2095226833293685100) · [AI HOT 聚合入口](https://aihot.virxact.com/items/cmtkh71ky017vrolly7trswyx)

【可信度/待核验点】功能、平台与套餐范围来自 Claude 官方帖及其串联说明；真实稳定性、耗额速度和权限隔离效果尚无独立验证。

## 3. NVIDIA 同意以 129.303 亿美元收购 Hugging Face

【事实】**已证实。** NVIDIA 官方宣布已同意以 12,930,300,000 美元收购 Hugging Face。官方承诺 Hugging Face 继续保持开放平台，支持各模型、框架、云、推理服务商及多类加速器，并明确不要求使用 NVIDIA 算力。AI HOT 显示该事件有 17 个独立信源跟进。

【影响】Hugging Face 已是开放模型、数据集和应用分发的关键基础设施，控制权进入芯片与全栈平台公司后，长期的默认推理栈、商业条款、排序曝光和生态中立性都值得重新评估。官方承诺降低了立刻迁移的必要，但不能把承诺当成永久架构保证。

【动作】暂不迁移，也不恐慌囤积；对真正依赖的模型、数据集和 Space 建清单，固定 revision/commit，保存许可证与必要本地快照，部署流程避免只接受 Hugging Face 单一下载入口。后续重点监控 API/托管推理价格、条款、私有仓库政策和非 NVIDIA 后端支持是否变化。

【证据】[NVIDIA 官方公告](https://blogs.nvidia.com/blog/nvidia-to-acquire-hugging-face) · [AI HOT 聚合入口](https://aihot.virxact.com/items/cmtli5yd109u4row52i1xg9j4)

【可信度/待核验点】交易金额、协议与开放承诺均来自收购方第一方；“同意收购”不等于已完成交割，监管审批、最终条款及收购后执行仍待观察。
