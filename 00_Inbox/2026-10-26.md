# AI / Agent 战略雷达 · 2026-10-26

Kimi 的额度问题已从个人反馈升级为官方承认：保留评测候选，但先验证稳定性，不迁移生产任务。

## 1. Kimi 承认限流与额外额度消耗，补偿不等于问题已解决

【事实】已核验 Kimi 官方公告：K3.1 Pro 订阅存在限流及不必要的额度消耗；官方宣布向各档订阅用户一次性恢复月度额度的 25%，已用量不足 25% 的归零。官方称已调整套餐参数，并正在减少不必要的子 Agent 调用与输出长度。这不是永久提额，也不是 API 降价公告，不能写成额度全部清零或问题已彻底解决。

【影响】这是对 10 月 24 日报告的实质更新：当时单个用户的额度吐槽不足以推断普遍问题，现在问题本身已有官方确认。对拟进行的财报证据抽取评测，除正确率外还需检查限流、完整任务的实际额度消耗和中断续跑；榜单成绩不足以证明长任务可以稳定交付。没有证据表明昱桥已订阅或受影响，不假定存在可领取补偿。

【动作】已回查官方原帖，并将 AI HOT 报道与个人额度反馈合并为同一事件。建议维持 Hermes + Codex + Claude Code 主栈；Kimi 保留为对照候选，暂不因补偿购买订阅或迁移定时任务。如已有订阅，先核对账户用量调整，再用公开材料做小规模验收；评测同时记录任务完成情况、额度与中断。未登录账户、消费额度或修改生产配置。

【证据】[Kimi 官方致歉与补偿原帖](https://x.com/Kimi_Moonshot/status/2114450610724708492)；[IT之家转载的中文公告](https://www.ithome.com/1/017/723.htm)；[AI HOT 聚合入口](https://aihot.news/items/qzp95at6fpxmnd251zsidaard)。AI HOT 用于发现事件，关键事实已回到第一方原文核验。

【可信度/待核验点】问题承认、补偿规则与调整方向为已核验的官方声明；账户实际到账、限流是否解除、调整后的任务质量及额度效率尚未实测。官方英文与中文转载对到账时间的表述存在时区差异，因此不承诺北京时间的具体到账时刻；以账户实际变化为准。
