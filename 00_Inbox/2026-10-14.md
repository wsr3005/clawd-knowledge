# AI / Agent 战略雷达 · 2026-10-14

一句话结论：桌面端存储优化值得关注；Argon 只作为有期限的成本候选；Agent 安全检查必须覆盖配置写入，不能只盯命令执行。

## 1. ChatGPT / Codex 桌面端优化存储：别误当成 CLI 或整盘瘦身

【事实】已核验 @thsottiaux 原帖：ChatGPT 与 Codex 桌面应用已推出磁盘状态存储优化，作者预计该部分占用减少 60%。这是发布方预期，不是本机实测，也不是应用全部占用或整块磁盘减少 60%。本次只读检查在 /Applications 找到 ChatGPT.app，版本为 26.930.51102；在 /Applications 和用户 Applications 两个常规位置未找到 Codex.app。

【影响】昱桥主盘空间紧张，这项变化与已安装的 ChatGPT 桌面端直接相关；但不能套用于 Codex CLI、Hermes 会话或项目缓存，也不能据此断言当前版本已经获得优化。

【动作】已核验发布方原文并检查常规安装位置与版本，未升级、清缓存或删除会话。建议下次正常更新 ChatGPT 时，将状态目录占用的前后比较纳入验收；不为兑现“60%”手动删除未知目录，现有 T7 归档策略保持不变。

【证据】[发布方原帖](https://x.com/thsottiaux/status/2110151780478927344)；本机应用 Info.plist 与常规安装位置只读检查。

【可信度/待核验点】优化发布声明已核验；具体生效版本、是否处理历史状态以及本机实际释放空间均待核验。常规路径未发现 Codex.app 不代表其他路径绝无安装。

## 2. Gemini 4 Argon：引入价有截止日，不为榜单换栈

【事实】已核验 Google 官方发布文：Argon 可经 AI Studio / Gemini 平台 API 使用；Gemini App 面向 Pro / Ultra 订阅者，Antigravity 面向 Ultra 订阅者。每百万 token 引入价为输入 2 美元、输出 10 美元；官方脚注明确引入期于 2026 年 11 月 30 日结束，之后适用输入 4 美元、输出 20 美元。上述是官方标价与开放范围，不代表昱桥账户实际可用或当前订阅包含 API 费用。

【影响】对投资证据提取、长文研究等任务，它新增了潜在的成本对照选项，但当前优惠不能当长期单位成本。也没有本机证据证明它能替代 Hermes、Codex、Claude Code 的既有分工，或改善小说商业稿质量。

【动作】已将权威 X、个人 X 与 AI HOT 的同一发布事件合并，并回查官方正文和价格脚注。建议不新增订阅、不迁移主控；只有现有任务出现明确质量或成本瓶颈，再经预算授权用同一验收样本对照测试，并按优惠期结束后的标价核算长期成本。本次未调用付费 API。

【证据】[Google 官方发布与价格脚注](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-argon/)。聚合线索与署名：[AI HOT](https://aihot.news/items/smxxtw5ca2c9jscojk4ppe5hf)。

【可信度/待核验点】官方标价、优惠截止日和入口已核验；账户地区限制、实际额度、任务成功率及每次合格交付成本未实测。不采用聚合摘要里的性能胜负结论。

## 3. Copilot 配置写入漏洞：安全边界必须落到文件和权限

【事实】已核验漏洞报告者 Johann Rehberger 的技术原文：CVE-2026-103572 涉及 Visual Studio / SQL Server Management Studio 的 Copilot 共享组件，路径校验与 Windows 文件名规范化差异可使受保护配置被改写，进而触发命令执行；报告包含间接提示注入路径。作者披露微软于 10 月 13 日发布修复。本次微软 MSRC 原始公告页面未成功读取，因此补丁覆盖版本及厂商措辞尚未独立核验。

【影响】这不是“昱桥的 macOS / Hermes 已中招”的证据。真正影响我们的，是安全验收范围：只阻止危险 shell 命令不够，Agent 修改 MCP、工具可执行路径或自动批准配置，也可能改变后续执行权限。外部文章、仓库和工具返回值只能作为数据，不能授权这类修改。

【动作】建议将“配置写入是否可绕过审批”列为下一次 Agent 安全验收项：保护 MCP 与工具启动配置，按操作系统规范化后的实际目标检查路径，并将外部内容驱动的修改隔离在低权限环境。若项目使用 Windows Visual Studio / SSMS，应先核对微软修复版本再更新。本次仅核验披露，未改安全配置、未运行漏洞载荷，也未将 Windows 问题泛化成本机故障。

【证据】[研究者原始披露](https://embracethered.com/blog/posts/2026/visual-studio-copilot-remote-code-execution/)；[微软公告入口（本次未读到正文）](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-103572)。聚合线索与署名：[AI HOT](https://aihot.news/items/o8h7g7pscq0qrlenoadabbb96)。

【可信度/待核验点】技术机制与披露时间线已回到研究者原文核验，非本次复现；修复发布属于研究者陈述，微软版本清单待核实。本机与自建 Agent 是否存在同类缺陷尚未审计。
