# AI / Agent 战略雷达 · 2026-10-29

优先核对现有订阅附带的 API 额度，但别把它当成 Codex 扩容；Carbon 尚未普遍开放，不值得现在迁移主栈。

## 1. OpenAI 订阅附送 API 额度：真正的机会在自动化，不在 Codex 扩容

【事实】已核验 OpenAI 官方公告与帮助中心：符合条件的 Pro 100／200／500 套餐，每完整月度账期分别附带 100／200／500 美元 API 额度；Business 按付费席位汇总，月度工作区上限为 500 美元，并非每人都有 500 美元。Plus 不适用。付费订阅需已生效至少 7 天，还受开放批次及国家限制，需要主动激活并绑定一个 API 组织。首次额度按账期剩余时间折算，月度额度到期不结转。关键排除项：既不增加登录态 Codex／ChatGPT 用量，也不覆盖通过 API key 使用 Codex 的费用。

【影响】对昱桥最有价值的是降低小说评测、研究资料处理等独立 API 工作流的现金成本，而不是解决当前 Codex 限额。前提是现有账号符合资格、实际到账，且具体模型与调用方式受覆盖；不能据此认定当前 Hermes 登录态调用已获得补贴。免费额度耗尽后，如组织仍有已购额度，请求会继续消耗已购额度，不能把赠送余额当作硬预算保险。

【动作】已核对领取路径、覆盖边界及超额行为。建议先在现有订阅的 Billing 页面确认资格、接收组织、实际金额与到期日，再决定是否给独立 API 任务分配预算；不为赠额升级订阅，不开自动充值。任何接入须先核对调用覆盖并设置应用侧预算熔断。本次未登录账号、领取额度、生成密钥或更改计费。

【证据】[OpenAI 官方公告及跟帖](https://x.com/OpenAIDevs/status/2115583698074755078)；[官方资格、激活与计费条款](https://help.openai.com/en/articles/20001626-api-credits-benefit-for-eligible-chatgpt-subscriptions)；[官方领取入口](https://chatgpt.com/settings/billing)。

【可信度/待核验点】政策与限制已回第一方原文核验；昱桥订阅档位、区域资格、接收组织、到账金额及现有任务是否受覆盖均未核验。不是“已领取”或“已省下”的报告。

## 2. Gemini 4 Carbon：先看可用范围，不跟着榜单换工具

【事实】Google 10 月 28 日官方公告明确：Carbon 本周先向部分网络安全防御团队开放，再通过 Fairwind 逐步扩大到可信合作方；面向普通开发者、企业及消费者的普遍开放日期尚未公布。Google 称其适合长程工程任务，内部团队观察到连续多天执行；这是厂商内部观察，不是我们的复现结果。

【影响】对投资研究长流程和代码库维护有潜在意义，但“已经发布”不等于昱桥现在能用。当前没有足够理由改动 Hermes＋Codex＋Claude Code 主栈，更不应因为长程能力宣传而放宽发布、花钱或破坏性操作的审批边界。

【动作】已核验官方开放范围，将其限定为后续评测候选，不安排现在的接入或迁移。建议以普通开发者正式可用为启动条件，再用既有真实任务对照成功率、人工接管次数和总成本；保持现有模型与权限设置不变。本次未申请访问或运行模型测试。

【证据】[Google 第一方公告](https://deepmind.google/blog/gemini-4-carbon-our-next-frontier-model/)；[AI HOT 聚合入口](https://aihot.news/items/fjeloaahylonpc0pv5tduusud)。AI HOT 用于发现事件，最终可用范围以官方原文为准。

【可信度/待核验点】发布日期与分阶段开放已核验；长程能力仅为厂商自报。普通开发者开放日期、账号可用性及对我们业务的实际改善仍待验证，不据排行榜认定更适合当前项目。
