## 1. GPT-6.2 扣额修正：同样任务更耗套餐额度，补偿重置不是永久扩容

【事实】已核验 OpenAI 的 Tibo 原帖：GPT-6.2 Astra／Sol 上线时错误给予了用量折扣，现已修正；官方原文称，相比上周，使用 Astra／Sol 会分别“快 40%／25% 触达上限”。其他模型不受此次修正影响，历史用量差额不追收；公告承诺为 Go、Plus、Pro、Business 用户增加一次可留存的重置。官方帮助中心明确：收到重置不等于已经刷新额度，它不增加永久上限，也不是 API 余额；覆盖范围和到期时间应在账号内核对。

【影响】若 Codex 工程、回测或小说任务选用了 GPT-6.2，上周的任务容量经验不能原样沿用。不能把“更快触顶”改写成“额度直接少了相同比例”，也不能外推为 API 标价上涨，或认定当前 Hermes 的 gpt-6-astra 同样受影响。

【动作】已核对完整公告和重置规则。建议下次安排 GPT-6.2 长任务前先查用量页，按真实扣额重新安排任务；确认补偿到账及期限，在需要时使用免费留存重置，不误点单独收费的即时重置。保留任务检查点，不因这则公告加购或自动换模型。本次未访问个人用量页、兑换重置、改变调度或发起模型评测。

【证据】[Tibo 第一方完整公告](https://x.com/thsottiaux/status/2125784147889393806)；[OpenAI 官方重置说明：领取、兑换、范围与有效期](https://help.openai.com/en/articles/20001498-how-resets-work-in-codex)。

【可信度/待核验点】官方公布的修正与补偿规则已核验；昱桥账号的具体模型使用、扣额变化、补偿到账和到期时间未核验。没有将公告中的百分比折算成实际可多跑或少跑的任务量。

## 2. UI SDK：驾驶舱可以直接向 Agent 暴露控件动作，但权限不能靠默认值

【事实】已核验项目发布说明与文档：UI SDK 处于测试版，把焦点、选择、弹层等交互拆成可组合行为，并提供 React、Vue、Svelte、Solid、Web Components 接口。接入后的组件可通过 createAgent 提供状态读取、查询和动作调用；这不是让 Agent 自动接管任意网页。权限文档明确：未提供 allow 时，普通受支持动作默认可执行；标记 data-agent-confirm 的操作另须确认。多步动作中途失败不会回滚此前步骤；直接调用组件 API 也不会运行键盘、鼠标事件中的校验。

【影响】对 AI 原生投资驾驶舱，价值不是换皮，而是让“筛选日期、展开证据、切换视图”成为有结构、可核对结果的动作，减少依赖截图定位的机会；效果尚未实测。反过来，若沿用只在点击事件里写风控的做法，Agent 的操作路径可能绕开那层校验。界面接入不应顺带获得交易权限。

【动作】已将产品展示与权限文档分开核验。建议只在独立原型中评测筛选和证据展开，不重构现有驾驶舱：显式列出允许动作，校验放在状态变更回调及后端，完成后回读实际值；实盘下单、资金操作及对外发布不接入这一试点。验收同时检查误操作拒绝与部分失败后的状态，不只看页面是否好看。本次未安装依赖、修改项目或启用 Agent 控件桥接。

【证据】[UI SDK 官方发布：测试版与框架范围](https://ui-sdk.dev/docs/core/changelog/introducing-ui-sdk)；[Agent 接入：状态、动作及返回结果](https://ui-sdk.dev/docs/agents/connect-an-agent)；[权限文档：默认行为、确认、校验与部分失败](https://ui-sdk.dev/docs/agents/connect-an-agent/permissions)；[shadcn 原始说明帖](https://x.com/shadcn/status/2126032449582813307)。

【可信度/待核验点】项目公布的接口与权限边界已核验；本机兼容性、可靠性及收益未实测。不采信官网速度与成本宣传为昱桥项目收益，也不将前端确认机制视为后端授权或交易风控的替代品。

## 3. Open Artifact：从生成 PPT 走向“人改、批注、Agent 续改”，先补协作环节

【事实】已核验作者项目：Open Artifact 由 baoyu-design 演变而来，以本地文件和编辑页面承载幻灯片、文档等作品，并提供 Claude Code／Codex 插件和批注返回会话的路径。相比 10 月 30 日仅核到新版预告与目录差异，本轮可读到独立插件接入文档及具体会话限制：Claude Code 的 monitor 只在交互会话中运行；纯命令行 codex exec 的空闲线程要在恢复时接收排队消息，不能当作自动后台续跑。当前仓库许可证为 Apache-2.0。Cindy 集成仍是作者预告，不计入已上线能力。

【影响】对客户 PPT 和研究材料，潜在收益是减少“指出哪一页、复制反馈、等待重做”的搬运，而不是另换一个 Agent。它更适合作为现有 Claude Code／Codex 的可视化返工层；没有证据表明应替换 PPT Master，也不能把通用 Skill 入口当作 Hermes 已经完成适配。

【动作】已核对项目、插件限制、幻灯片规范与许可证。建议遇到下一次真实 PPT 返工时再做隔离对照：人工改标题并回存、批注准确回到原会话、Agent 续改不覆盖人工修改、中文字体和 PPTX 导出可用。先限本机，不开启局域网分享或服务器自动发布；云端模型处理材料的权限仍单独核验。当前许可证不等于第三方素材和全部依赖均已完成商用授权审查。本次未安装插件、运行仓库代码、开放服务或上传客户资料。
