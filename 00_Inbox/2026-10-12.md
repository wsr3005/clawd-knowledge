## 1. Codex：Sol 默认上下文升至 500k，订阅用量不收长上下文附加费

【事实】已核验 OpenAI 的 Tibo 原始公告：GPT-6.1 Sol 在 Codex 与 Work 中的默认上下文从 272k 提至 500k；可手动调整，模型最大上下文为 1M。作者随后明确补充：使用订阅额度时，GPT-6.1 Sol 不收取长上下文费用。该声明不是无限额度，也没有宣布 API 同步免除长上下文费用。

【影响】对股票驾驶舱跨文件开发、较长的工程验收任务，这降低了选择 Sol 长会话时的一项成本顾虑，并可能减少上下文压缩造成的约束丢失；后者是预期收益，不是本机实测结果。它不证明 Sol 的任务质量优于 Astra，也不意味着 Hermes 当前模型自动获得同样窗口。昨天针对 Claude Code 的提前压缩建议不能原样套到此次 Codex 订阅计量变化上。

【动作】建议下一次已有的上下文密集型 Codex 工程任务，在确认使用 GPT-6.1 Sol、订阅计费及实际窗口后，先按新默认值执行；记录压缩次数、验收遗漏与账户用量，再决定是否调整。不主动拉满 1M，不为用额度增加任务，不切换 Hermes 的 Astra 主控。本次已完成公告与费用补充的双链接核验，并排除近期已推送的重置额度和 Anthropic 安全事件；未更改模型配置、启动付费评测或核验个人账户生效情况。
