## 1. 昨日建议收紧：Qwen-Image-2.1 商用需要单独授权

【事实】已核验 Qwen 官方 Hugging Face 模型卡及 LICENSE。该权重采用 Qwen Research License Agreement；第 1.i 条将 Non-Commercial 定义为仅研究或评估，第 2.a 条明确授权仅限非商业目的，第 2.b 条要求商业用途另取商业许可。官方申请联系地址为 model-business@notice.qwencloud.com。这是今天补齐的许可证据，不是声称许可今天发生变更，也不能把宣传中的“开源”理解为无条件商用。

【影响】昨天将其列入 PPT 与商业素材工作流的候选验证，并保留许可待核验项；今天该项已明确，判断应收紧：不能在未获适用授权时自行部署该权重用于客户 PPT、产品广告或小说商业宣传素材生产。透明图生成能力仍有研究价值，但不能先接单交付、再补许可。

【动作】本日报已把建议从“商业素材候选验证”收紧为“仅研究评估候选，商业生产先过授权门”。若使用第三方托管服务，先核对该服务是否取得适用授权，以及用户协议是否覆盖我们的具体商用场景；不能推定使用在线 Demo 就绕过限制。未下载模型、生成商业素材、联系厂商或购买授权。

【证据】[Qwen 官方权重许可全文](https://huggingface.co/Qwen/Qwen-Image-2.1/blob/main/LICENSE)；[官方模型卡及 License 声明](https://huggingface.co/Qwen/Qwen-Image-2.1)。聚合线索署名：[AI HOT：Qwen-Image-2.1 发布](https://aihot.news/items/cmu9tfhu904turokx2vfjy34f)。

## 2. ZCode 仓库快照披露：先审查客户端外传，再谈模型是否开放

【事实】已回查研究者 ferstar 的原始调查，而非仅引用聚合标题。研究者称其逆向分析、快照清单与日志显示：ZCode 登录后会在后台打包工作区，包含 Git 历史、LFS 缓存、reflog 和部分全局配置，并通过上传链路发送到云端；“Optimize Experience”与“Repo Snapshot Indexing”开关不阻止本地打包及上传流程。其展示的一个归档处于 pending 且有失败重试记录，因此不能把这一归档写成已成功泄露。以上是研究者的一手披露，不是 Hermes 独立复现或厂商确认。

【影响】对我们的 Hermes、Codex、Claude Code 工具选择，新增的是准入检查项：开放模型权重不等于客户端不会外传；只审查 Agent 的工具调用权限，也可能漏掉客户端后台进程。若上传范围含 Git 对象库，即便当前文件已删去密钥，历史版本仍可能带出敏感内容。没有证据表明昱桥使用了受影响版本或发生泄露，不据此要求停用现有主力工具。

【动作】建议暂不将 ZCode 接入股票、BTC、小说或客户项目的真实仓库；如需评估，只用无秘密、无私有历史的隔离样例，先检查后台网络流量、快照范围和可验证的退出机制。已采取：追溯原始调查，区分“存在上传链路”与“具体归档上传成功”；未安装 ZCode、删除快照或执行调查文章中的文件锁定命令。此项是新工具准入建议，不是宣称已完成本机安全审计。

【证据】[ferstar 原始调查：Inside ZCode](https://blog.ferstar.org/en/posts/zcode-silent-workspace-snapshot-upload/)；[Tokenstead 二次分析](https://tokenstead.ai/guides/zcode-silent-git-history-upload)。聚合线索署名：[AI HOT：ZCode 快照与上传争议](https://aihot.news/items/cmu6y9sjz0jbyrowkh7tus28l)。

【可信度/待核验点】原始调查已读取，技术行为仍属研究方陈述；适用版本、当前版本是否修复、厂商回应、实际上传成功范围以及本机是否安装均未独立核验。不将研究者对厂商动机的判断当作事实。
