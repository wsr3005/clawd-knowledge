# AI / Agent 战略雷达 · 2026-11-10

一句话结论：Fable 5.2 值得利用套餐窗口做难题对照测试，不急着切默认模型；dot 多机能力已公告，但文档冲突未消除，先不扩大机器授权。

## 1. Fable 5.2：优先用已有额度试难题，别把促销当永久免费

【事实】已核验 Anthropic 发布页与促销条款：Fable 5.2 已发布，API 标准价为每百万输入 / 输出 token 8 / 40 美元，快速模式为 16 / 80 美元。Pro 和 Team 标准席位在 2026 年 11 月 9 日至 11 月 16 日 23:59（美国太平洋时间）可用最多一半周额度运行 Fable；达到额度或活动结束后，若开启 usage credits，会转为按量计费。符合活动条件的 Max、Ultra 等席位可获得额度重置；重置不是提高上限，且使用后不能撤销。官方仍建议多数日常编程和知识任务从 Opus 5.5 开始，而非一律换 Fable。

【影响】对我们的 Claude Code 工程与研究质询，变化是多了一个可以低增量成本验证的困难任务候选，不是已有证据证明应该替换 Hermes / Codex 默认模型。API 标价不等于完成任务的实际成本；跑得更快也不等于更便宜。

【动作】建议先在账户 Usage 页面确认资格、额度和额外付费开关，再用已有套餐对照一个投资驾驶舱工程难题或证据链审查任务；比较验收通过情况、遗漏、耗时与用量。不为评测新开付费，不自动使用不可撤销的 reset，不开启快速模式。本次已完成官方条款核验，未改模型配置、未消费测试额度。

【证据】[Anthropic 发布原文](https://www.anthropic.com/claude-fable-and-mythos-5-2)；[官方促销与重置条款](https://support.claude.com/en/articles/17506494)；[账户用量入口](https://claude.ai/settings/usage)。

【可信度/待核验点】发布、价格和活动规则由第一方原文证实；昱桥账户资格与剩余额度尚未读取，实际任务收益尚未测试。另需注意：官方说明非适用企业客户有用于安全监控的 30 天数据留存；客户资料与交易凭证不能因模型升级而放宽输入边界。

## 2. dot 公告支持多机：有分离执行环境的价值，但先处理文档矛盾

【事实】OpenAI Developers 官方公告称，同一个 dot 可以连接多台本地电脑并指定任务使用哪台，举例是在专用机器构建和测试、同时继续在笔记本开发。但本次读取的官方连接指南仍写着“同一时间只能连接一台个人电脑”，两处第一方表述尚不一致。指南同时明确：连接会跨任务持续；离线不等于撤销权限；dot 的本地访问授权与 Codex 连接是分开的。

【影响】若账户已获得新能力，投资驾驶舱的界面测试和环境复现有机会从日常工作机分离。但它不等于安全沙箱，也不能据公告推断我们的账户已可用，更没有理由因此给含交易密钥、浏览器登录态或客户数据的机器增加长期授权。

【动作】建议保持现有 Hermes + Codex + Claude Code 主流程。仅在已有备用测试机且账户界面明确支持时考虑隔离试点：使用脱敏项目、不带生产凭证，验收后显式撤销访问。未核验前不采购设备、不连接主力机。本次只核验公告与指南，未新增任何机器授权。

【证据】[OpenAI Developers 原始公告](https://x.com/OpenAIDevs/status/2119883176726409645)；[官方电脑连接与权限指南](https://learn.chatgpt.com/docs/dots/computers-and-apps)。

【可信度/待核验点】多机公告及持久授权说明已核验；多机当前实际可用范围、账户资格，以及文档是否尚未更新仍待核实，不采用中文转述中的套餐、区域与并行限制细节。
