# AI/Agent 战略雷达｜2026-09-28

一句话结论：视觉旧评测需要按模型重新判断；产品演示视频出现可复用的代码化制作案例，但两者都不足以支持直接换模型或另开工具战线。

## 1. OpenAI 修复 Sol / Luna 图像理解缺陷：旧视觉结论需要复测

【事实】已核验 OpenAI Developers 原帖：官方称已修复影响 GPT-6 Sol 与 GPT-6 Luna 图像理解的缺陷，涉及 API、Codex 中的视觉任务，包括电脑操作。原帖未提供提升幅度，也没有提及 Astra。

【影响】若此前用 Sol / Luna 做过界面截图检查、图表识读或图像理解，其失败结果不宜直接代表修复后的表现。这不构成更换当前默认 Astra 的依据，也不能证明消毒中心器械识别准确率已经提高。

【动作】建议下次相关视觉任务先复测原先失败的同一批非敏感样本，保持提示词与验收标准不变，记录模型、测试时间及错误类型；复测前不据此调整工具栈或对客户承诺效果。本次已核验公告，未调用模型进行视觉实测，未上传客户图片。

【证据】[OpenAI Developers 官方修复公告](https://x.com/OpenAIDevs/status/2104252306447544447)。

【可信度/待核验点】官方修复声明已证实；实际提升、个人使用环境是否受益及具体任务准确率待实测。不能把修复外推到 Astra 或所有 OpenAI 模型。

## 2. 产品演示视频可以先走代码绘制，不必先采购视频生成工具

【事实】已核验宝玉本人发布的案例与提示词：其称使用 Claude Code 中的 Opus 5.5 为 BaoCut 制作宣传视频。公开流程要求先读项目代码与原型确认功能，再用 Canvas 确定性逐帧绘制，以共用节拍表驱动画面和音效，先抽关键帧自查，再输出完整视频。这是作者案例，不是我们复现验证的性能结果。

【影响】对投资驾驶舱、已有技能或未来产品的功能演示，这提供了一条沿用现有 Claude Code 工具栈的候选流程。价值在于把真实功能、画面与修改过程绑定，而非证明某模型审美领先。该路线适合示意动画和界面叙事，不能据此替代实拍、复杂短剧或泛化的视频生成需求。

【动作】建议在下一次确有演示需求时，先用现有项目的一段真实功能制作短样片，验收功能表述准确、画面可读、修改可控及实际制作成本，再决定是否扩展。暂不新购视频工具、不另建平台。本次仅核验公开流程，未制作视频；复用时单独检查字体、音频与图像素材许可，不照搬案例中的品牌和角色。

【证据】[宝玉：BaoCut 宣传视频案例与完整制作提示词](https://x.com/dotey/status/2104111348388941915)。

【可信度/待核验点】原帖和流程文本已核验；视频最终质量、代码可运行性、耗时、成本及商业授权未独立验证。“无需 API key”不等于免费，“本机制作”也不证明调用云端模型时资料不外发。
