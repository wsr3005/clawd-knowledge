## 1. Cursor 插件市场出现恶意 Claude Code 包：本机定点初筛未命中

【事实】已核验 Cursor 官方安全通告：其扩展市场分发的 Anthropic.claude-code 2.1.313 存在恶意修改，并非 Anthropic 开发；载荷尝试添加 SSH 授权密钥、建立反向隧道及持久化。Cursor 称已下架恶意包并关闭攻击服务器，但明确提醒：仅卸载扩展可能不足以清除独立持久化脚本。官方没有证据表明其他版本或官方发行渠道受影响，不能扩大为“Claude Code 全线被攻破”。

【影响】昱桥的 Agent 工作环境连接代码、研究资料和账号凭据，插件供应链问题可能越过单一编辑器边界。是否通过 Cursor 安装过涉事包，比是否使用 Claude 模型更重要；CLI 用户也不能仅凭产品名称被判定中招。

【动作】已执行本机只读定点检查：当前 ~/.cursor/extensions 无名称含 claude 的条目，~/.vscode/extensions 不存在；~/.ssh/authorized_keys 未发现 svc-telemetry 标记；~/.config/.smt、~/.config/.smtk 和 ~/Library/LaunchAgents/com.apple.sysmond.plist 均不存在。没有删除文件、执行远端修复脚本或更改凭据。建议维持现有主栈，不从转发链接安装所谓修复插件；若其他设备或历史安装记录命中涉事包，应按官方通告隔离主机、排查持久化，并从可信设备轮换可访问凭据。

【证据】[Cursor 官方安全通告、入侵指标及处置步骤](https://cursor.com/blog/claude-code-extension-security-notice)；[Cursor 官方公告](https://x.com/cursor_ai/status/2116074289053175808)。本机结果来自本次只读文件与扩展目录检查。

【可信度/待核验点】事件机制已核验第一方通告；本机仅完成当前用户标准路径和指定指标初筛，不是完整取证，未覆盖历史安装记录、其他用户、远端主机、自定义扩展目录或全部进程与网络遥测。“未命中”不等于证明从未受影响。

【事实】已核验 Claude 官方原帖：Max 5x 更名 Max，Max 20x 更名 Ultra，价格仍分别为每月 100 美元与 200 美元，现有订阅无需操作。已验证 Ultra 账号取消五小时限制，先覆盖多数现有订阅者；较新账号在验证前保留临时限制，解除时会收到邮件。每周限额不变。

【影响】若昱桥现有账号属于已生效 Ultra，Claude Code 的长时间研究、质询与批量任务可少受短窗口打断；但更容易集中消耗每周预算。这改变任务排布，不构成加购理由，也不代表 API 或 Hermes 当前调用路径自动受益。
