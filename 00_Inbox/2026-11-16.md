# AI / Agent 战略雷达｜2026-11-16

先把纠错变成自动检查、把多 Agent 的提交权管住；Claude 办公任务再试 Medium 档，不急着换栈或加并发。

## 1. 纠错应进入代码与测试，不只是继续加长 AGENTS.md

【事实】已核验 Lauren Tan 在 AI Engineer 大会上的演讲及页面所附完整机器转录。她把约束分成不同层次：先用接口设计、架构、静态检查与测试限制错误，再用运行验证检验实际行为，文字规则留给无法直接编码的判断。团队案例包括禁止错误的跨目录依赖、让 Agent 实际运行应用并提交截图、录屏等验收材料。限制 React useEffect、严控注释是其特定产品的选择，不是所有仓库应照抄的规则。

【影响】对投资驾驶舱和 Codex 工程任务，值得改变的是“怎样纠错、怎样验收”，不是换编辑器。反复提醒不能替代会失败的测试；能编译、模型说完成，也不能证明数据展示、交互与异常处理正确。这与继续增加审查 Agent 是不同的投入方向。

【动作】建议把下一次已批准的工程修复按这个顺序交付：先用测试复现错误，再修复并证明测试由失败转为通过；能由类型、接口或静态检查拦住的问题，优先在那里约束；界面改动附关键操作路径的运行证据，同时保留 diff 审查。AGENTS.md 仍保留目标、权限和判断规则，不做全面删注释或自动合并。本次已把上述要求归档为验收建议，未修改项目代码或安装插件。

【证据】[大会原文与完整机器转录](https://ai.engineer/code/2026/talks/lauren-tan)；[演讲录像](https://youtu.be/O_zcc6Xl12g)。

【可信度/待核验点】方法归属与适用条件：高，已读完整机器转录，未逐帧观看录像，转录可能有识别误差。团队产能与回滚数据属于讲者自报，本报告不据此承诺我们的提效或质量；未做本地对照实验。

## 2. 多 Agent 的风险不只在“摸鱼”：提交时可能还没读到关键要求

【事实】已核验 Anthropic 11 月 11 日的研究说明《Worse Together》及论文摘要；不是今天新发布的论文。研究比较多个用户各自委托 Agent、共同使用预算或订单等资源的情形。在其模拟环境中，团队协调会出现延迟行动、覆盖他人要求、无依据代述他人意见等问题；一个关键失败点是执行者在读取待处理消息前就提交订单。统一负责人改善了预算分配，但在订单场景并非同样有效；平台阻止执行者在有未读消息时结账，是该场景有效的缓解措施。

【影响】这不能推导成“多 Agent 一定不如单 Agent”。但对我们的 Kanban、Claude Code 与 Codex 协作，存在可迁移的风险：大家各做各的任务，却共同修改一个仓库或任务状态；“消息已发出”不等于负责提交的一方已经纳入最新约束。这是工程类比，不是本机故障诊断。

【动作】建议下一轮协作采用“可并行执行、受控提交”：实现工作使用独立工作树，合并与任务完成状态由明确负责人处理；提交前重新读取验收要求、待处理消息及目标版本，遇到新增约束先重验；子任务不得擅自取消别人的工作或替用户声称已批准。上述检查不能只写在聊天提示里，进入调度器或合并检查才构成强约束。本次已归档设计依据，未改 Kanban、权限或运行中的任务。

【证据】[Anthropic 官方研究说明](https://alignment.anthropic.com/2026/worse-together/)；[论文与提交历史](https://arxiv.org/abs/2610.00583)。

【可信度/待核验点】官方说明与实验边界：高；本地收益与风险发生率：未知。论文初稿提交于 9 月 30 日，本轮是近期官方解读被中文实践源重新传播，不包装成当天新实验。模拟环境、受测模型与我们当前配置不同；未复现实验，也不把团队规模与表现的关系解释成人类式“懒惰”。

## 3. Opus 办公指南：先给成品标准、从 Medium 起步，省钱仍要看实测

【事实】已回查 Anthropic 11 月 12 日官方指南：对 Opus 5.5，建议首条消息说清目标、最终产物及何时停下来询问；从 Medium 思考档起步，任务卡住再提高；删除泛泛的“think hard”“think carefully”，并可直接提供图表原图。原文仍把明确、范围窄的任务列为 Sonnet 适用场景，并没有要求所有工作都换 Opus。文中节省输出 token 的数字来自早期测试者的特定比较，不是所有任务的成本保证。

【影响】对研究报告、客户材料和 PPT，新增价值是减少机械的分步提示与不必要的高思考档，而不是再买一个工具。它不意味着可以跳过昱桥要求的方案、风格确认，也不意味着图表取数可以免复核；更不能把知识工作演示外推为小说写作质量已达标。

【动作】建议在需求与风格已确认的下一份材料上，用现有合规额度做一次对照：同一批脱敏资料、同样的成品要求与证据标准，比较 Medium 与原有流程的返工、事实错误、耗时和实际用量；失败后再提高档位。可用任务描述：“直接交付指定格式成品；数字保留来源，缺证据就标缺口；涉及范围变化或外部操作时停下确认。”本次只完成原文核验与任务模板归档，未切换 Hermes 默认模型、开启连接器或消费评测额度。

【证据】[Anthropic 官方知识工作指南](https://claude.com/resources/articles/using-claude-opus-5-5-as-your-daily-driver-for-knowledge-work)。

【可信度/待核验点】官方建议：高；厂商及早期测试者效果不能视为昱桥任务实测。个人账号可用性、模型实际用量和成品质量未验证。本条不重复报道模型发布或降价；中文 B 级转述中的泛化收益不作为采信依据。
