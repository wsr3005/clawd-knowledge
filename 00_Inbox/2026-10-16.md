# AI / Agent 战略雷达 · 2026-10-16

结论：先守住 Claude Code 的额外计费边界；Agent 沙箱有了可复用的开源底座，但不值得为此立即扩建工具栈。

## 1. Claude 快速模式：买的是输出速度，不是更强能力或套餐内加速

【事实】已核验官方 API 与 Claude Code 文档：Opus 5.5 fast mode 输入/输出价格为每百万 token 8/40 美元；仍是同一模型，不改变能力。官方宣称最高 2.5 倍输出速度，不代表整个任务耗时缩短到相同比例。订阅用户通过 usage credits 支付，不包含在订阅额度内。Claude Code 的交互式开关默认跨会话保留，可用 `fastModePerSessionOptIn: true` 要求逐会话开启。

【影响】我们的 Claude Code 研究、质询与长任务容易把一次临时加速变成持续额外开销。工具等待、测试和网络耗时不会因为输出加速自动消失，不能按宣传倍率推算整条流水线收益。

【动作】建议长任务保持标准模式；只有人正在等待的交互式排障才考虑付费加速，并先明确预算。建议采用逐会话开启设置，避免遗留开关。此次已核验计费与持久化规则，未修改配置、未开启付费功能。

【证据】[Claude Code 官方文档](https://code.claude.com/docs/en/fast-mode)；[API 官方文档](https://platform.claude.com/docs/en/build-with-claude/fast-mode)；线索署名：[AI HOT](https://aihot.news/items/e2ssy0a7scpnel6ppyl3r9f2t)。

【可信度/待核验点】计费与开关规则：高，官方文档直接支持。候选消息称“结束研究预览、移除等待名单”，但本次读取的两份官方文档仍标 research preview，因此不将该发布状态当作已证实事实。实际账号开放情况、当前本机开关与真实提速未核验。

## 2. Perplexity SPACE：Agent 代码执行沙箱可复用，不必先自建一整套

【事实】已核验 Perplexity 官方公开仓库：SPACE 使用 Apache-2.0 许可证，通过 HTTP API 管理隔离的 Firecracker microVM、Linux 执行环境、命令输出和沙箱生命周期。官方提供安装、首个沙箱、认证、故障排查及 E2B 兼容层文档；推荐入门路径包含本地 Kind 集群。它是执行基础设施，不是替代 Hermes、Codex 或 Claude Code 的主控助手。

【影响】未来把 Agent 工作流交给客户、执行用户提供的代码时，已有一个可评估的隔离底座，减少从零开发沙箱生命周期的必要性。但开源不等于部署免费，也不证明默认配置就满足客户数据隔离要求。

【动作】将其作为“客户侧不可信代码执行”场景的候选，而不是现在增加的新战线。真正进入该场景时，先核验宿主条件、网络出口、凭证隔离、超时回收与故障恢复，再做试运行；当前不部署、不迁移现有工具栈。此次已核验仓库与架构说明，未做运行实测。

【证据】[Perplexity 官方 SPACE 仓库](https://github.com/perplexityai/space)；[官方安装文档入口](https://github.com/perplexityai/SPACE/blob/main/docs/installation.md)；线索署名：[AI HOT](https://aihot.news/items/fgtsm4cnci4asmyhhflxzfsga)。

【可信度/待核验点】仓库开放、许可证和文档所述架构：高。宿主兼容性、生产安全性和实际运维成本仍待验证；未采信宣传中的服务规模，也不将其描述为 Mac 上即装即用。
