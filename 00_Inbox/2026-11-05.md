## 1. Images 2.6 进入 Codex：从生成图片走向就地修改

【事实】已核验 OpenAI Developers 官方公告及同帖补充：GPT-Image-2.6 进入 Codex 与 API，API 提供 Flare 和 Sunburst 两种图像模型；Codex 的图像编辑改为直接在覆盖层中进行，而非打开侧栏。官方同时介绍了向 API 提交带标记的图片来指定编辑位置，以及从静态角色图制作循环 GIF 的能力。官方称新 API 图像模型生成速度提高 50%，Sunburst 在中、高质量设置下跨次编辑的细节更一致——这些是厂商声明，不是我们的实测。

【影响】对昱桥的 PPT 配图、演示素材和产品界面制作，实际价值是可能减少“生成后另开工具修改”的往返；局部编辑若能保留未指定区域，可减少反复返工。这是工作流推断，不能据此认为整套 PPT 制作提速 50%，也不能把 GIF 能力当作短剧视频生产能力。此次无需新增 Agent 框架。

【动作】建议下次已有配图任务优先在 Codex 中验收：用同一张非敏感素材做局部改色、背景修改和连续编辑，检查中文文字、主体一致性、非目标区域漂移、导出结果及实际额度消耗；只有成品合格才纳入 PPT 流程。本次已完成官方原帖核验、事件合并及与近期日报去重，未安装新工具、未调用付费图像 API、未变更套餐。SVG 导出、全档位可用等二手说法未纳入已证实事实。

【证据】[OpenAI Developers 官方发布](https://x.com/OpenAIDevs/status/2118124753340756055)；[循环 GIF 用法](https://x.com/OpenAIDevs/status/2118124755442151684)；[带标记图片的 API 编辑说明](https://x.com/OpenAIDevs/status/2118124761867845847)；[Codex 覆盖层编辑说明](https://x.com/OpenAIDevs/status/2118124764413718953)。补充内容由官方发布帖展开页面读取。
