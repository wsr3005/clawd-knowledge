# AI / Agent 战略情报｜2026-08-08

**一句话结论：** Agent 能力继续从“单会话执行”迈向跨会话协作与自动安全审查，但 Astra 的临界网络安全信号说明：权限隔离、最小授权和人工审批必须先于能力升级。

## 1. Astra 触及 OpenAI 首个“临界”网络安全能力边界

【事实】OpenAI 官方称，对未发布模型 Astra 的初步评估显示其智能体编程与网络安全能力显著提升，现阶段无法排除达到 Preparedness Framework 的 Critical 阈值；因此暂停不符合强化安全要求的内部活动，并增加隔离测试、网络与工具访问限制、权重保护、监控和沙箱。OpenAI 同时明确 Astra 与此前 Hugging Face 事件无关。AI HOT 显示该事件至少有 6 个独立信源报道。

【影响】这不是普通模型升级，而是 Agent 基础设施的安全边界变化：当模型能自主串联漏洞、凭证和横向移动时，“可信模型 + 宽权限”已经是错误架构。昱桥当前的 Hermes/Codex/Claude Code 自动化，尤其涉及浏览器、GitHub、远程机器和长期凭证的流程，都应按不可信执行体设计。

【动作】立即把下一阶段自动化的默认规则定为：任务级短期凭证、网络/工具白名单、隔离工作区、敏感动作人工批准、日志可追溯；在这些控制落实前，不因新模型能力更强而扩大自主权限。

【证据】[OpenAI：Responding to the next frontier of critical cyber capabilities](https://openai.com/index/responding-next-frontier-critical-cyber-capabilities/)；[AI HOT 聚合入口](https://aihot.virxact.com/items/cmsjk6eiz0byoroo5cc4bcwg6)

【可信度/待核验点】高；“Critical”是 OpenAI 基于初步评估作出的风险分类，官方措辞是“无法排除”，并非已经完成最终定级，也未公布 Astra 的公开可用日期。

## 2. Codex Security Review 可直接挂到 GitHub PR

【事实】OpenAI 已将 Codex Security Review 以 research preview 形式接入 GitHub PR：可在 PR 打开、每次 push 或普通 Code Review 运行时自动触发，也可用 `@codex security review` 手动触发；它结合 PR diff、仓库上下文和自定义 threat model。自动审查默认只在 PR 中报告 High/Critical，手动审查默认报告 Medium 以上。官方文档同时警告：发布到 PR 的发现继承该 PR 的可见性。

【影响】这能把“开发完成后再补安全”前移到合并门禁，尤其适合 Agent 高频改代码的仓库；但公开仓库里直接贴漏洞细节也可能反向泄露攻击路径，不能无脑全量开启。

【动作】建议先在一个私有、活跃仓库做受控试点：提交仓库 threat model，仅自动报告 High/Critical，记录误报、漏报与真实修复率；公开仓库先保留人工触发和人工披露。此次未代为修改 GitHub/Codex 设置，因为这会改变外部服务行为。

【证据】[OpenAI 官方文档：Security Review](https://developers.openai.com/codex/security/security-review)；[OpenAI Developers 公告](https://x.com/OpenAIDevs/status/2085482310636560830)

【可信度/待核验点】高；当前仍是 research preview，具体账号是否已获得入口需在 Codex 设置页实测，使用限制可能变化。

## 3. Claude Code 会话可直接互发摘要

【事实】Claude Developers 官方宣布：Claude Code 会话现在可以互相发送消息；传递的是摘要，而不是完整历史记录或文件。会话可以双向问答，也可在发现变更影响另一会话时主动通知；官方称更新 Claude Code 后可在 macOS 和 Linux 使用。

【影响】这直接降低多终端、多任务并行时的人工转述成本，适合把“实现、测试、安全审查”拆成独立会话并让它们同步依赖变化；但摘要通信不是共享状态，不能替代 Git、任务板或验收文件。

【动作】将它列为 Claude Code 多会话编排的优先试验能力：只传任务状态、接口变化和阻塞项，最终事实仍落到 Git commit、测试结果和 Kanban；避免把摘要当成已验证交付。

【证据】[Claude Developers 官方公告及后续说明](https://x.com/ClaudeDevs/status/2085817074816070014)；[Claude Code：Agent teams 文档](https://code.claude.com/docs/en/agent-teams)

【可信度/待核验点】中高；官方 X 已确认跨会话消息、摘要边界及平台范围，但本次抓取未定位到该新功能独立文档页，具体命令/UI 与版本要求需本机更新后验证。
