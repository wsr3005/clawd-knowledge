# AI/Agent 战略雷达｜2026-10-03

一句话结论：Apple 将收紧 Mac 完全磁盘访问授权；对本机自动化，先守住权限边界，不要把未来的访问失败当成需要全盘放权的故障。

## 1. Apple 将收紧完全磁盘访问：本机 Agent 的权限依赖需要纳入升级验收

【事实】已证实：Apple 在 10 月 2 日开发者公告中表示，将增加控制措施，要求用户以非常明确的操作授予应用 Full Disk Access（完全磁盘访问权限）。公告指出，这类权限很大程度上绕过既有隐私控制，可能暴露文件、邮件、消息及浏览历史；自主 AI Agent 会放大风险。原文未公布上线日期、适用系统版本、具体交互或既有授权的处理办法，因此不能称“当前 Mac 已被限制”。AI HOT 将此与 Meta Muse 私信争议聚合；本条仅采用 Apple 官方公告，不对争议中的数据访问作判定。

【影响】昱桥的 Hermes、Codex、Claude Code 在 Mac 本机执行，已有工作流使用 Chrome Default 登录态，也涉及项目目录和外置 T7。推断：后续系统升级或授权变化可能影响受保护数据读取，但并非所有项目文件、外置盘或命令行工具都会受影响。需要防住两个错误：把权限拒绝误判成采集逻辑坏了；为恢复自动化直接给不可信 Agent 或插件全盘访问。昨日已报告的 Claude mods 也不能被当作沙箱：Anthropic 明确说明其与 Claude Code 拥有相同机器访问能力，且不受沙箱隔离。

【动作】已回 Apple 第一方公告核验，并与昨日 mods 报告去重；未改系统权限、未升级、未访问 Cookie 内容。建议将“原有读取能力是否保持、是否出现新的明确授权步骤”列入下一次 macOS/Agent 升级验收：分别检查普通项目目录、确有必要的受保护路径和 T7。若出现拒绝，先记录具体路径、执行进程与错误，再判断最小必要授权；不绕过系统保护，不以全盘授权替代定位。对新增 mods，先审查代码和来源，再考虑安装；保留人工授权边界。

【证据】[Apple 官方：Updates to Full Disk Access in macOS](https://developer.apple.com/news/?id=p6zjojqw)；[Anthropic 官方：mods 的权限与非沙箱边界](https://claude.com/blog/claude-code-mods)；[The Verge 原始报道](https://www.theverge.com/tech/1004295/apple-limit-mac-disk-access-ai-agents)；线索来自 [AI HOT 聚合入口](https://aihot.news/items/gwtipws3qkxm941aqz5iluhdi)。

【可信度/待核验点】政策方向与 mods 权限边界有第一方原文支持；上线时间、受影响版本、现有授权迁移和对本机工作流的实际影响均未证实。本次不是本机权限审计，未发现或宣称当前已有故障。
