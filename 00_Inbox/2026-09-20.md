## 1. Claude Code 2.1.277：比共用规则更重要的是沙箱与静默失败修复

【事实】官方发布说明已核验：修复 sandbox.excludedCommands 的通配符只匹配复合 Bash 命令一部分、却使整个命令豁免沙箱的问题；现在各部分都必须匹配。另修复 claude -p 与 Agent SDK 遇内部错误后可能无结果挂起的问题，改为报错并以退出码 1 结束；资源不足导致 Grep/Glob 无法启动时，不再伪装成“没有匹配”。昨日已报道的 AGENTS.md 回退支持现有正式发布说明佐证，并明确暂不支持 Bedrock、Vertex、Foundry。

【影响】对 Claude Code 工程执行和未来无人值守任务，判断：沙箱豁免边界和“检索失败≠没有证据”直接影响安全与验收，比重复宣传文件名兼容更重要。正式发布说明也补上了昨日公告与可见日志不一致的证据缺口；不代表本机已升级或已受影响。

【动作】建议把该版本修复列入下一次获批工具维护的优先核验项：检查实际版本及沙箱例外配置，再验证失败任务的退出码、错误记录与超时保护。外层调度仍须验收产物，不能把进程正常退出视为交付成功。已采取：核对正式发布说明，提取新增安全与可靠性证据，未升级软件、修改沙箱或项目规则。

【证据】[Claude Code 官方 v2.1.277 发布说明](https://github.com/anthropics/claude-code/releases/tag/v2.1.277)。聚合线索署名：[AI HOT](https://aihot.news/items/cmu7bu9xu04terogr4pz0w6r4)。

## 2. Jev：可评估为雷达预筛器，不能作为安全裁判或交易开关

【事实】已核验 TypeSafe 官方发布文章：Jev 接收状态和结构化问题，返回带概率的类型化决策而非生成文本；官方公告为早期访问，并设候补名单。公告列价为每百万输入 token 0.042 美元、输出免费，这是供应商标价，不是我们的实测成本。更关键的是，官方 jev-1.13 限制文档明确承认：数值与日期比较不可靠，无关上下文会降低准确性，对抗性内容和注入指令可以改变答案。因此“不会产生类型错误”不能推导为“事实判断不会错”。

【影响】判断：可用来对 AI 雷达或投资证据候选做语义预筛，把昂贵模型留给原文核验与因果推演；它不是替换 Hermes、Codex、Claude Code 的新主力模型。误删重要政策证据的损失可能超过调用费节省；带置信度也不意味着置信度在我们的中文任务中已经校准。

【动作】建议仅列入离线对照候选：用已有候选材料及人工判定比较漏报、端到端延迟和总成本；初期只旁路打分，不自动丢弃证据。日期窗口、价格阈值和计数继续交给代码，发布、花钱和交易授权继续由确定性规则与人工把关。已采取：对照官方能力声明与失败模式，删除社区“快/便宜多少倍”的未经本地验证结论；未开通付费、上传资料或接入生产。

【证据】[TypeSafe 官方发布文章](https://typesafe.ai/blog/introducing-system-one-models-and-jev)；[官方 jev-1.13 失败模式](https://docs.typesafe.ai/model-jaggedness/jev-1.13)。聚合线索署名：[AI HOT](https://aihot.news/items/cmu7hc2e80aavrogr7vbwhcjm)。
