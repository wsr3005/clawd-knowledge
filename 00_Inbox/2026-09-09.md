## 1. 数学成果争议暴露数据边界问题，不等于已证实泄密

【事实】**已核验第一方声明：** OpenAI 在 9 月 8 日的 Navier–Stokes 公告中否认研究人员或智能体曾在对方公开前看到其工作，也否认专门访问用户数据来解决该问题；同时称不能排除其产品使用中产生的去标识化数据帮助改进了模型。这是当事方声明，不是独立调查结论。现行数据政策说明：个人服务内容可能用于训练，退出后新对话不用于训练；商业产品及 API 默认不训练，主动选择共享另论。这不是今日新改的政策。

【影响】对昱桥真正相关的不是数学圈输赢，而是未发表小说、未公开投资研究和客户资料的上传边界。去标识化不等于商业机密可以放心上传；API 默认不训练也不等于零留存，更不能直接套用到第三方中转或订阅登录通道。

【动作】**建议：** 下次上传敏感材料前，先确认实际服务、登录/调用通道及训练共享设置；个人 ChatGPT 检查 Data Controls，客户资料先脱敏并确认使用权限。不要因这次争议断言“OpenAI 偷了用户论文”，也不要把未发布内部模型的成果当成当前 Codex 能力承诺。**已采取：** 对照公告和数据政策，剔除“已证实泄密”与“现有模型已能复现”的推断；未操作账户设置。

【证据】[OpenAI 原始公告及 Concurrent work 声明](https://openai.com/index/navier-stokes-solution)；[OpenAI 数据使用政策](https://openai.com/policies/how-your-data-is-used-to-improve-model-performance/)；聚合线索署名：[AI HOT](https://aihot.news/items/cmtszna9e04isro5woti0ixg6)。

【可信度/待核验点】公告与政策文本已核验；争议事实未经独立裁定，昱桥实际账户设置及调用通道的数据条款未核验。本文不判定数学证明是否成立。

## 2. Claude 官方把降本审计做成 Skill：先查浪费，再换模型

【事实】**官方文档已证实：** Anthropic 于 9 月 8 日发布降本指南，称已将相关指导纳入 claude-api skill，并介绍 `/claude-api prompt-audit`、`/claude-api cost-optimize`、`/claude-api hillclimb`。关注点包括缓存前缀稳定性、过时或相互矛盾的提示词、与任务匹配的推理强度。原文明确指出，动态时间戳、工具定义变化等可能破坏缓存，机械重复验证也可能徒增消耗。

【影响】这比“中档思考一定比最高档聪明”的单次体验更能指导 Claude Code 研究工作流。昱桥的长指令、Skills 与多轮研究值得审计，但省成本不能以删除证据门、真实执行验证或外部操作授权为代价；Claude 的经验也不能直接当作 Astra 的实测结论。

【动作】**建议：** 下一轮 Claude 工作流优化先在副本上审计提示词，再用同一批真实任务比较验收通过情况、耗时和实际费用。清理重复仪式，保留必要核验；API 链路再检查缓存命中。**已采取：** 核验官方命令与适用范围；未安装技能、改配置或启动付费测试。不要假定本机现有 claude-api 版本已包含这些命令。

【证据】[Anthropic 官方降本指南](https://claude.com/blog/reducing-cost-and-improving-performance-with-claude-platform)；[官方 claude-api skill 源码入口](https://github.com/anthropics/skills/tree/main/skills/claude-api)；聚合线索署名：[AI HOT](https://aihot.news/items/cmtsz50zn02mtro5w6ywm1xml)。

## 3. Images 2.5：有价值的是局部改图，不是再添一个生图工具

【事实】**官方发布已证实：** OpenAI 于 9 月 8 日宣布 Images 2.5 面向 ChatGPT、ChatGPT Work 和 Codex 各档位用户推出，API 同步提供 GPT‑Image‑2.5 Flare 与 GPT‑Image‑2.5 Sunburst。新增草图参考 Sketch、图上评论编辑与模板；官方称参考主体保真、局部编辑及多轮一致性有所改进。Sunburst 面向精细创意编辑，生成时间更长。上述效果是厂商描述，不是本地测试结果。

【影响】可进入小说封面、PPT 配图与商品素材的返工流程：先定布局，再局部修订，避免每次重画整张。如果实际能保住人物、构图和未指定区域，才有减少交付返工的价值。不能由此推断中文排版已可靠、版权风险消失，或器械识别准确率会提高。

【动作】**建议：** 下一次现有素材任务，先在已有账户权限内用参考图测试连续局部修改，验收未改区域、人物一致性和中文字样；排版文字优先保留为可编辑图层。通过小样才讨论 API 接入，不为新品单独开项目或购买额度。**已采取：** 合并官网、权威 X 与中文转述的同一发布事件，核验第一方可用范围；未生成素材或产生费用。

【证据】[OpenAI Images 2.5 原始发布](https://openai.com/index/introducing-chatgpt-images-2-5)；聚合线索署名：[AI HOT](https://aihot.news/items/cmtt0pw2p018pro9owlhpi092)。

【可信度/待核验点】发布及官方能力描述已核验；账户实际入口、API 单价、商用条款和真实编辑质量未在本次验证，不宣称免费、降价或可直接商用交付。
