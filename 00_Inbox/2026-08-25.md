# 2026-08-25 AI / Agent 战略情报

一句话结论：今天真正要改的是安全边界——有主机权限的 Agent 不应经过不受信任中转；ChatGPT Work 与 Kiro 值得观察和隔离测试，但还不值得迁移核心工作流。

## 1. Codex 中转链路出现凭证窃取脚本注入报告

【事实】V2EX 用户 theguagua 报告：使用 Codex 中转站时发现一段疑似窃取 SSH、API Key 等开发环境凭证的 Shell 脚本；其后再次测试时，注入被伪装成 “Environment health check”。安全媒体对所示脚本的二次分析称，其目标包含环境变量、SSH 私钥、云凭证、包管理器凭证和 Shell 历史。现有证据能确认“公开事件报告及复现说法存在”，但没有独立取证可以证明中转站主动投毒；二次报道认为也可能是中转站自身遭上游脚本注入。

【影响】Hermes、Codex、Claude Code 这类 Agent 一旦拥有终端与文件权限，中转服务不只是能看到上下文，还能篡改模型返回或工具调用。省下的 Token 钱无法覆盖 SSH、云账号、代码仓库和商业资料被接管的尾部风险。

【动作】把“有主机权限的 Agent 只走官方直连或可审计、可信云厂商链路”设为硬边界；任何不受信任中转只能进入无宿主目录挂载、无长期凭证、无生产网络权限的临时 VM/容器，并禁用无人值守全权限。若曾使用涉事或来源不明的中转，应轮换其可触达的 SSH/API/云凭证并审计异常调用。

【证据】[V2EX 原始事件帖](https://www.v2ex.com/t/1233104) · [当事人回复记录](https://www.v2ex.com/member/theguagua) · [二次脚本分析](https://www.163.com/dy/article/L432OBOA0511A5GF.html) · [X 线索](https://x.com/binghe/status/2091533899394580868)

【可信度/待核验点】中等。用户报告与后续回复可直接核验；脚本能力来自二次分析，攻击源头、影响范围及中转站责任尚未独立确认。

## 2. ChatGPT Work 暴露了“连接器权限先于能力”的现实瓶颈

【事实】OpenAI 官方说明 ChatGPT Work 可跨应用、文件、浏览器和本机执行长任务，并支持插件与定时任务。TechCrunch 8 月 24 日的独立上手显示：记者尝试只授予云盘“读取”权限时多次失败，最终移动端提示需完整访问；记者因此没有连接邮箱中的采访与草稿，也明确不愿连接银行账户。这是单个实测案例，不代表所有连接器都存在同样限制。

【影响】ChatGPT Work 正把 Codex/OpenClaw 式能力包装成大众产品，但当前价值与风险都取决于权限模型。对昱桥而言，它可以成为非敏感办公流的快速试验场，却不能因为界面简单就绕过 Hermes 工作流现有的最小权限、可审计与人工审批边界。

【动作】暂不迁移核心知识库、邮件、发布和账号操作；若试用，只连接专门创建的低敏感测试账号/文件夹，先验证读取范围、跨源引用与外发审批，再决定是否扩大权限。把“能否精确授予只读及单目录权限”作为准入门槛，而不是只比较任务完成率。

【证据】[OpenAI 官方产品说明](https://openai.com/index/chatgpt-for-your-most-ambitious-work/) · [TechCrunch 独立上手](https://techcrunch.com/2026/08/24/openai-is-building-an-ai-agent-for-everything-will-everyone-use-them) · [AI HOT 聚合入口](https://aihot.virxact.com/items/cmt7e3m7h234gro73wwwhymb0)

【可信度/待核验点】高（产品能力与可用范围为官方信息）；中等（权限摩擦来自单一记者的实际体验，需在昱桥自己的账号与连接器上复测）。

## 3. GPT-5.6 全家桶进入 Kiro，形成新的同模型 Harness 对照组

【事实】OpenAI 8 月 24 日宣布 GPT-5.6 Sol、Terra、Luna 已可在 AWS 的 Kiro 中使用。官方称 OpenAI 与 AWS 的 Terminal-Bench 2.1 测试里，Terra 在 Kiro 中完成成功任务的成本约降低 82%；但公告没有写明该降幅的对照基线、样本规模和完整测试配置，因此不能直接外推到真实仓库。

【影响】同一模型在不同 Harness 中的成本与成功率可能显著不同。Kiro 的 spec-driven 上下文、Skills/AGENTS.md/MCP 兼容性，使它成为 Codex/Hermes 的有效对照，而不是一个需要立刻迁移的新 IDE。

【动作】仅加入下一轮同任务 Harness 测试：选一个隔离、可重复、带测试验收的小仓库，对比 Codex/Hermes 与 Kiro+Terra 的一次成功率、总 Token/credits、墙钟时间、返工次数和变更质量；在自有结果出来前，不采用“82% 降本”作为采购或迁移依据。

【证据】[OpenAI 官方公告](https://openai.com/index/gpt-5-6-in-kiro) · [Kiro 官方站](https://kiro.dev/) · [AI HOT 聚合入口](https://aihot.virxact.com/items/cmt7nzq6i2c27ro73tqxagz44)

【可信度/待核验点】高（可用性）；中等偏低（82% 为厂商联合测试且关键基线未披露）。
