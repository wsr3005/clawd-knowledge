# AI/Agent 战略雷达｜2026-10-02

一句话结论：先补执行护栏，再按任务验证降本；不换主模型，不为新功能盲目升级。

## 1. Claude Code mods：护栏能进入执行链，但本机尚未达到版本门槛

【事实】已核验 Anthropic 10 月 1 日官方教程：mods 是随插件分发、常驻会话的 JavaScript/TypeScript 模块，能观察、改写或拒绝事件，并绘制界面；官方要求 Claude Code 2.1.287 或更高版本，且提醒 API 可能随版本变化。今天本机执行 `claude --version` 返回 `2.1.283 (Claude Code)`，尚未达到该要求。AI HOT 的发布消息和教程已合并为同一事件。

【影响】对 Hermes＋Claude Code＋Kanban 工作流，价值不在美化终端，而在把危险命令确认、改动回放和上下文观察放进实际执行链。它提供实现护栏的新接口，但不能据此认为插件本身就是完整安全隔离；能改写行为的第三方插件也扩大了信任边界。

【动作】已核验教程并检查本机版本，未升级、未安装插件、未修改权限。建议后续先在隔离项目评估只读的改动回放，再验证危险操作拦截及绕过路径；保留现有权限规则和人工批准边界。升级前核对目标版本生成的类型声明，不直接照抄教程 API 到当前环境。

【证据】[Anthropic 官方教程](https://claude.dev/blog/getting-started-with-claude-code-mods/)；[AI HOT 聚合入口](https://aihot.news/items/sbvvdrkyjbtob4gp4iwwtyar1)。本机证据：`claude --version` → `2.1.283 (Claude Code)`。

【可信度/待核验点】功能说明与版本门槛有官方原文支持；本机版本已实测。mods 加载、插件兼容性、拦截可靠性未实测，不宣称护栏已部署。

## 2. 任务分流有新增实测证据：可降本，但“质量无显著变化”不等于等效

【事实】已核验 LangChain 10 月 1 日公布的 Open SWE 自测：在 973 个线程的 A/B 测试中，相对全部使用 GPT-6 Astra，分流组每线程中位成本为 0.94 美元，对照组为 2.61 美元；作者报告下降 64%。合并 PR 的线程占比分别为 29.2% 和 27.3%，p=0.49。路由只在会话起点选择模型，不随中途任务变化重选；作者另一次“全部使用便宜模型”的测试因工程师反馈质量问题提前终止，未得到统计上有意义的结果。

【影响】相较此前的路由概念与离线基准，新增的是实际工程工作流的对照证据及失败边界：值得评估低风险任务分流，不值得全面降级。该结果不证明质量等效，也不能直接外推到小说质量、投资判断或昱桥的订阅额度；按 token 计费的降本比例并不等于 Codex 订阅用量节省。

【动作】保持 Hermes 默认 Astra 不变，不引入新框架。建议先以既有历史任务做离线对照：将检索整理、格式转换与复杂工程分开，比较任务通过率、人工返工、重试后的总成本和耗时；关键投资判断及难修复任务不纳入首批降级。已核验实验方法和原文限制；未运行本地 A/B、未改路由、未发起付费测试。

【证据】[LangChain 原始实验与实现说明](https://www.langchain.com/blog/how-to-build-a-model-router-in-the-harness)；[AI HOT 聚合入口](https://aihot.news/items/t6jf7f9e5zbw4sxftwim9wgk7)。

【可信度/待核验点】已确认这些数字及限制出自第一方实验披露，非独立复现。PR 合并是代理指标，不覆盖全部质量；本地收益仍待测试，不承诺节省比例。
