# AI / Agent 战略雷达 · 2026-10-24

优先关注可接管的独立桌面与低成本模型分工；不因新榜单更换主力工具栈。

## 1. Hermes Spaces：桌面自动化有了人机交接入口

【事实】已核验 Nous Research 官方公告：新的 Cua Spaces 插件可让 Hermes 在自有硬件上的 Linux、macOS 或 Windows Space 中工作，团队成员可打开、实时观看、介入，再交还给 Hermes。官方文档插件目录可访问，但本次提取未得到具体插件配置说明。

【影响】对需要操作网页、桌面软件及检查交付物的工作流，价值不是再添一个聊天入口，而是让昱桥在自动化卡住时接管。可作为 PPT 等可视化交付的候选执行环境；是否真正避免占用日常桌面、隔离账号与文件，不能由公告直接推出。

【动作】建议仅在下一次确有桌面自动化需求时评估：验收实时观察、人工接管、交还后续跑以及文件/凭据隔离。保持现有 Hermes + Codex + Claude Code 主栈；本次完成公告和文档入口核验，未安装插件、授权账号或变更桌面环境。

【证据】[Nous Research 官方公告](https://x.com/NousResearch/status/2113391397760041329)；[Hermes 官方插件目录](https://hermes-agent.nousresearch.com/docs/plugins)。

【可信度/待核验点】功能发布由第一方确认；费用、硬件条件、平台限制、隔离强度与本机接入步骤未核验，未做运行实测。“能接管”不等于可以绕过发布、付款和删除的人工授权。

## 2. MiniMax M3.1 Flash：新增低成本执行模型候选，权重发布已有官方确认

【事实】已核验官方博客报价：每百万 token 输入 0.15 美元、输出 0.60 美元、缓存输入 0.015 美元；博客列明 API、M Plan 和 MiniMax Code 可用。博客仍写权重后续发布，但官方 X 新公告已明确权重公开，并链接 Hugging Face 和 ModelScope；两处发布状态表述不同，本报告以新公告记录“官方宣布公开”，不声称已下载验证。

【影响】值得评估的不是替换主力推理模型，而是将雷达材料预处理、结构化抽取等可验收步骤交给低成本执行模型，保留主力模型作证据审查。单价低不等于完成任务更便宜，重试、遗漏与工具调用失败可能抵消收益；API 报价不代表现有订阅额度增加。

【动作】建议下一轮成本评测优先复用历史雷达材料，以来源链接保留、字段正确、事件去重和总调用成本作为验收项，先离线比较再考虑接入。本次已交叉核验价格与权重公告，未购买套餐、发起付费测试或切换生产模型。

【证据】[MiniMax 官方博客与价格](https://www.minimax.io/blog/minimax-m31f)；[官方权重发布公告](https://x.com/MiniMax_AI/status/2113436864904610008)；[公告链接的模型仓库](https://huggingface.co/MiniMaxAI/MiniMax-M3.1-Flash)；[AI HOT 聚合入口](https://aihot.news/items/wrnv8dd428iozlj5xax99zbmj)。

【可信度/待核验点】价格和发布声明已由第一方核验；模型仓库内容、许可证与商用限制、实际账单和任务成功率未核验。未采用推广帖套餐优惠、免费截止日或厂商性能提升比例作为决策依据。

## 3. Kimi K3.1 Pro：可进入财报证据链评测，不应直接接管投资结论

【事实】已核验 Kimi 技术博客：K3.1 Pro 提供百万 token 上下文，在 Kimi 网页、Work、Code 和 API 可用；完整权重承诺于 11 月 4 日前发布，因此不能写成“权重已开放”。官方重点展示财务建模与研究能力，但其幻觉改善数据来自内部压力测试，原文明示不代表日常错误率。

【影响】对瓶颈优势研究，长上下文值得用于跨财报、公告的证据定位测试，但不能证明引用完整、时间截点正确或投资判断可信。对当前工程主栈也没有足够证据支持迁移；个人套餐耗尽的单条反馈不足以推出普遍额度结论。

【动作】建议把它列为财报证据抽取的对照候选，仅使用公开、带时间截点的固定材料，检查原文定位、数字一致性及证据不足时是否拒绝下结论。只有同题验收与成本胜出才考虑模型分工；本次已核验原文，未新增工具、购买额度或运行模型对比。

【证据】[Kimi 官方技术博客](https://www.kimi.com/blog/kimi-k3-1-pro)；[AI HOT 聚合入口](https://aihot.news/items/okgjn7r72wo7c5j0bu3o1vbie)。

【可信度/待核验点】入口、上下文规模及权重发布承诺属于已核验的官方声明；实际可用额度、费用、真实财报任务表现和未来按期释出尚未验证。厂商自测不等于独立验证，不采用“幻觉下降”宣传数字作为投资安全保证。
