# AI / Agent 战略雷达 · 2026-10-08

一句话结论：先核对可用于自建 Agent 的月度 API 额度；Claude Code 新版有降本与修复，也有云端定时唤醒回退，不能盲目升级。

## 1. Claude 月度 API 赠额：能用于自建 Agent，不是 Claude Code 加时包

【事实】官方帮助中心确认：Max 5x 每月 100 美元、Max 20x 每月 200 美元；Team 按席位汇总、每月最多 500 美元。Free、Pro、Enterprise 不适用；新订阅者需满足七天资格。需绑定一个 Console 组织，绑定后不能自行更换；每个账期刷新、不结转。额度覆盖 Claude Platform API、Managed Agents 和 Agent SDK，不覆盖交互式 Claude Code、套餐额外用量或第三方云平台。用尽后若组织有已购余额或自动充值，会继续消耗；没有其他余额则请求停止。

【影响】这给当前自建自动化和模型对照提供了潜在预算，但不代表已到账，也不会增加 Claude Code 套餐上限。与昨日的一次性云端赠额是不同政策；也不能沿用旧 Agent SDK 赠额的资格判断。接入仍需采用官方 API 鉴权，不能把订阅登录凭证当通用 API 密钥。

【动作】建议已有合资格套餐时，先在账单页检查 API credits，再选定实际用于开发的 Console 组织；绑定前核对共享密钥、工作区消费上限和自动充值状态。不为赠额新购套餐。已核验完整帮助文档；本次未绑定组织、领取额度、改模型或启动付费调用。

【证据】[官方完整规则](https://support.claude.com/en/articles/17154008-monthly-api-credits-for-max-and-team-plans)；[Claude Devs 官方公告](https://x.com/ClaudeDevs/status/2107895957933408429)；线索来自 [AI HOT](https://aihot.news/items/ponkn6n046yorr5pg1yv3yjm5)。

【可信度/待核验点】政策已获第一方证实；昱桥当前套餐、资格、到账与 Console 扣费设置未核实。官方说明分批推出，看不到入口不等于不符合资格。

## 2. Claude Code 新版：Haiku 可试降本，但云端定时任务有明确回退

【事实】官方 v2.1.293 发布说明加入 claude-haiku-5-5：每百万 token 输入/输出为 0.10/0.50 美元，提示超过 100K 时为 0.50/2.50 美元，支持 1M 上下文。该版修复上下文压缩后误判已完成工作、部分后台消息丢失及 HTTP MCP 内存泄漏等问题；同时明确撤回 v2.1.290 的一项修复：云容器重启丢失待执行的 /loop 唤醒或定时任务后，会话仍可能保持休眠。本机实际执行 claude --version 返回 2.1.283。

【影响】长任务可靠性比模型发布热度更值得关注。Haiku 可列入摘要、分类、结构化提取的低成本候选，但不能凭价格替换小说主笔、投资判断或复杂工程模型。云端回退风险只针对上述场景，不能据此声称本机 Hermes cron 已受影响。

【动作】不自动升级。建议下一次维护用可回退环境测试压缩后续跑、后台消息接收、MCP 长连接；若依赖云端定时任务，必须另测容器重启后的唤醒与结果落地，验收前不把关键任务托付给它。Haiku 的比较以合格交付成本为准，保留长输入跨档计价。已核验官方发布说明及本机版本；未安装新版、未运行模型质量测试。

【证据】[Claude Code v2.1.293 官方发布说明](https://github.com/anthropics/claude-code/releases/tag/v2.1.293)；本地只读命令 claude --version；线索来自 [AI HOT](https://aihot.news/items/vd2lvzvjz4tujiqupl30ifq3k)。

【可信度/待核验点】版本、官方变更和列示价格已核验；修复效果未在本机复现，云端任务是否正在使用尚未检查。API 单价不是订阅套餐的实际账单。

## 3. Skills 应与工具一起加载：已有可参考实现，不必再换框架

【事实】LangChain 官方介绍 Deep Agents 新增技能绑定工具、运行时固定技能、线程内刷新技能。绑定工具在读取对应技能前不可调用；应用可把明确指定的技能提前放入上下文。支持会话中追加工具的模型可保留原缓存前缀；刷新技能列表可能改动系统提示并使缓存失效，并非所有动态加载都免费。

【影响】这为投资研究、小说生产和工程技能库提供了更明确的设计约束：让操作说明与工具同时到场，降低“找到工具却没读规则”的风险。它是工具暴露控制，不等同于完整安全授权，更不是迁移现有 Hermes／Codex／Claude Code 栈的理由。

【动作】建议后续技能工程验收加入三项检查：技能未读时相关工具是否被阻止；显式选择技能时是否确实预载；长会话修改技能后是否有可控刷新。当前只收录已核验的设计参考，不安装 Deep Agents，也不声称 Hermes 已具有同样机制。

【证据】[LangChain 官方说明](https://www.langchain.com/blog/revamping-skills-in-deep-agents)；线索来自 [AI HOT](https://aihot.news/items/m3vyz2bex4i58vffqfx586u3h)。

【可信度/待核验点】第一方功能说明已核验；跨模型缓存行为与当前工具栈适配未实测，不能承诺节省比例。
