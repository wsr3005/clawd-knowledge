# AI / Agent 战略雷达｜2026-11-12

把简单判断从昂贵生成流程中拆出来，同时借现成测试补可靠性；不换主力工具，不因发布会成绩直接上线。

## 1. Gemini Decisions API：雷达初筛有了专用低价判断接口

【事实】已核验 Google 11 月 11 日公告正文：Gemini Decision 1 通过 Gemini API / Google AI Studio 提供封闭选项判断，支持文本、图像、音频、视频和 PDF；单次最多评估 1,000 个问题，返回概率与置信度。官方定价为每百万输入 token 0.10 美元，输出不收费；共享输入每请求计费一次，各问题的指令与选项仍计入输入。Google Cloud 支持尚属即将推出，不能把它当作已经全面可用。

【影响】对 AI 情报和股票事件雷达，相关性筛选、事件类别、是否送深度研究等有限选项判断，可能不必每次调用主力模型生成长回答。这是现有工作流的前置筛选候选，不是替换 Hermes、Codex 或 Claude Code。实际节省取决于输入长度、误判及回退开销；置信度不是事实正确率，更不能授权交易。

【动作】建议仅列为离线对照评测候选：用已标注历史事件比较现有筛选器，优先检查关键事件漏报、置信度校准和含回退的实际成本；未证明可靠前不拦截生产消息，低置信度交回现有流程。已核验官方价格及计费边界；本次没有调用付费 API、开通账户或修改生产配置。

【证据】[Google 第一方发布正文](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api)；[官方文档入口](https://aistudio.google.com/docs/decisions-api)。

【可信度/待核验点】高：功能、价格与发布日见第一方正文。性能提升是厂商主张，本报告不据此承诺效果；账号地区资格、免费层限额、真实任务准确率及本地链路延迟均未实测。

## 2. Stanford CS329Z：可复用的是 Agent 测试设计，不是再造框架

【事实】已核验课程主页及官方 assignment1-harness 仓库：作业起始代码与测试公开，采用 MIT 许可。默认确定性测试不调用模型，用 ScriptedLM 回放固定回复；真实模型测试另外执行且会产生费用。README 明确把空回复、错误格式、截断工具调用、工具异常列入错误处理测试，并提供缓存、调用账本及预算限制机制。这是教学起始仓库，不是开箱即用的完整 Agent。

【影响】对 Hermes / Skills / Kanban，价值不是再学一套工具，而是给工具调用失败与长流程中断建立可复现验收案例。先用固定回复测流程，再用真实模型测效果，可以避免把每次调试都变成付费试错。

【动作】建议下一次相关工程变更时，参考其测试接口，把空输出、格式错误、调用截断、工具抛错作为回归场景；保留现有工具栈，不为课程重写 Agent。已核验仓库及复用许可；尚未下载、运行或移植测试，不声称现有系统通过这些测试。

【证据】[Stanford 课程主页](https://cs329z.stanford.edu)；[课程官方作业仓库与 README](https://github.com/cs329z/assignment1-harness)。

【可信度/待核验点】高：公开仓库、许可与测试机制有原文。未确认中文转述中的视频更新频率、首次公开日期和具体评分数字，故不采用；教学测试不能替代生产安全审计。
